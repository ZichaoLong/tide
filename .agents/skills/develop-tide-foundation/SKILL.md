# Develop Tide instances

Implement the current FC/HB main bindings from the fixed math snapshot. Semantic correctness comes first; performance second. Do not consult or reuse the retired foundation source/tests.

Use small independent formulas, parameter gradients, multiple optimizer steps and necessary continuation checks. Test each main candidate and useful combinations, not the Cartesian product. Production need not expose action traces, dependency journals, arbitrary internal roots or universal decoding. Keep basic configuration/run instructions and honest results. Interfaces and backend implementations may differ by instance; historical APIs and backend matrices impose no duty.

User instructions override historical guidance. Choose serial work, parallel tools or agents by benefit; coordinate resource use and conflicting edits. Main agent integrates and commits. Long jobs use frozen source, background.slice and explicit time/memory bounds.
