# Maintain Tide instances

Start from [project scope](../../../docs/project-scope.md),
[STATUS](../../../docs/STATUS.md) and [ROADMAP](../../../docs/ROADMAP.md).
The instance library is a continuing product route. A new adopted upstream
revision starts a new selection of bindings and implementation work; it does
not automatically activate the separate general-foundation route.

Keep one owner for each fact: scope for product decisions, ROADMAP for planned
work, STATUS for current handoff, contracts for behavior and measurement,
evidence for observed results. Skills supply methods, not another backlog.
Use short links to these owners rather than duplicating their contents.

Design interfaces around useful tensor computations, clear mathematical ownership
and replaceable modules. Share or separate instance/backend implementations by
benefit. Migrate costly interfaces explicitly instead of making compatibility
shape every calculation. Update the [architecture map](../../../docs/architecture.md)
and [consumer API](../../../docs/instances.md) when those boundaries change.

Retire superseded implementations, tests, configurations, commands and normative
documents together. Current-tree searches should find active material; Git keeps
the historical versions for explicitly requested investigation. Preserve concise,
applicable mechanisms in [performance lessons](../../../docs/performance-lessons.md)
with their source and limits, without restoring old architecture obligations.

For authorized artifact cleanup, follow
[retention](../../../docs/artifact-retention.md): identify ownership, live inputs,
consumer dependencies and unique uncommitted work before removal. A registered
worktree or ignored path is not by itself a disposable experiment.

Check navigation and the affected runnable entry points after governance changes.
Distinguish agreed targets, current implementation and measured qualification;
editing a scope document does not certify a feature. A fresh-context read of the
small entry set is useful when validating a substantial handoff change.
