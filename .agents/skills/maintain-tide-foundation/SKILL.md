# Maintain Tide instances

Keep the current instance library easy to run and modify without building a general framework.

Start at README, STATUS, ROADMAP and src/tide. Maintain only useful navigation and consumer instructions. Prefer direct model implementations and small shared mathematical helpers. Do not add compatibility wrappers, complete traceability ledgers or broad source audits as prerequisites to useful correctness/performance work. Keep user changes and historical result identities; Git retains retired implementation history.

User instructions override historical guidance. Choose serial work, parallel tools or agents by benefit; coordinate resource use and conflicting edits. Main agent integrates and commits. Long jobs use frozen source, background.slice and explicit time/memory bounds.
