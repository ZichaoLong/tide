# 脑科学启发的模型问题

本文从生物观察提出希望数字模型具有的能力，再讨论可能的机制与研究问题。局部回路、稀疏活动、群体协作、长程通路和多种时间尺度，为同时探索局部通信、可扩展容量与有效处理提供想像空间。设想可以先保留，随后逐步形成构造；当前某个方案的取舍尚不能穷尽这些方向。

生物事实与参考文献见[人脑信号传播调查](../background/neuroscience-survey.md)。这些启发与[研究意图](design-requirements-and-architecture.md)相连，具体函数和图由相应语义与应用文档定义。一个观察可以启发多种机制，下面的例子供后续选择和改写。

## 1. “稀疏”至少有四种含义

结构稀疏是连接数量相对稀少；群体稀疏是某时刻部分神经元活动更强；时间稀疏是单个神经元只在部分时间放电；功能稀疏是某些群体对特定任务贡献更显著。

神经元有阈值，亚阈值膜电位、局部突触及背景活动仍可能变化；轴突的解剖去向相对稳定。这些现象提示把连接范围、接收更新、发送和昂贵加工分别考虑。全局 Top-K 只给出其中一种数字选择方式，大尺度任务图上的“未激活”也不足以描述全部接收与状态变化。

这给出一种数字模型假设：分开接收更新与完整内容计算。按正典，在 Next 保留计算状态的绑定下，$\kappa=1$ 使全部候选保留更新，$\kappa=0$ 使仅激活候选保留更新；两种状态采用方式的效果可通过实验比较。

## 2. 微观变化与宏观功能

脑科学中的 representational drift 指微观活动或调谐变化而行为可能保持相对稳定。群体冗余、下游适应、稳态可塑性及不同时间尺度可能共同参与。它启发一个意图：允许内部细粒度分工变化，同时维持可用的整体功能。

数字模型可以据此追问：不同激活集合是否产生接近的固定接口表示？限制单节点残差贡献、提高激活集合的重叠、缩短一次选择持续限制可达分支的时间，是否有帮助？相关扰动界、比较对象和观测定义见[训练风险](../training/sparse-routing-risks-and-diagnostics.md)。

节点数量、单节点贡献、重叠程度和下游适应是不同的选择。单纯将候选从 16 增至 4096，尚未限制切换两个完整函数的差异；可以据此继续探索更细粒度的节点、共同背景或多条合作通路，而不必只沿节点数量外推。

## 3. 生物信用分配仍是开放问题

可参考的机制包括感觉预测误差、小脑误差信号、基底节奖励学习、eligibility trace、海马/皮层重放，以及神经调质对可塑性的影响。这些不同来源的信号提示研究多种学习支撑怎样协作；全脑信用分配的完整解释仍是开放问题。

数字模型可以研究局部辅助 loss、teacher representation matching、训练数据 replay 或受控 shadow 分支。训练重放不一定改变推理函数；推理中主动重演内部轨迹则是另一种状态与依赖结构。

生物体的长期学习还包含进化、发育、身体闭环和多种先验。数字模型可以选择可实现的训练信号与先验，观察哪些机制足以支持较长路径上的学习；具体选择与结果由下游实验记录。

## 4. 多条通路、汇合与时间尺度

真实脑网络存在相对稳定的感觉/运动通路、多级 hub、丘脑中继和多种重汇聚。这启发多个局部主通路、有限生命周期分支和层级接口的数字构型。固定加法 merge、来源聚合和选择性发送都可以作为数字机制分别研究；它们各有自己的数学定义。

快速反应与较慢上下文处理提示了两种不同问题：哪些内部结果决定当前输出，哪些只改变未来处理？Tide 的端口、正时延和持久状态可表达这类依赖；HB-Timed 与 LH 提供了[不同的探索构造](../../instances/backbone-design.md)。数学依赖确定之后，再研究实现何时能产生结果以及任务头如何使用它。

Hub 可以先被设想为少量摘要与钩子的载体，让其他通路利用已有细节继续加工。收集范围、状态容量和发送对象可共同调整；这一角色并不要求保存完整信息或广播给所有节点。其有效性及与普通通路的互补关系，需要放回具体图和训练中理解。

局部恢复与阈值可以启发显式选择历史。按逻辑时间保存数值和更新时间、在读取时计算有效衰减的完整例子见 [PDG §1.6](../../positive-delay-graph-finite-cut-learning-note.md#16-例按统一逻辑时间读取衰减状态)。将这种时间处理用于选择历史时，还需定义自己的 SelStep 与历史空间；当前带权局部支线使用单点历史。

## 5. 从启发到可推进的问题

| 生物启发 | 希望获得的能力 | 可以探索的机制与问题 |
| --- | --- | --- |
| 持续背景状态与稀疏放电 | 少量完整加工时仍积累可用历史 | 分开接收更新与 Full，比较以后读取到的私有记忆及准备成本 |
| 局部连接与长程通路并存 | 容量扩大后仍有足够的信息合作 | 有限邻域、层级通路、摘要钩子怎样配合，怎样映射到物理通信 |
| 群体冗余与表征漂移 | 局部分工变化时保持整体可用性 | 小贡献、激活重叠和下游适应能否减少输出扰动 |
| 多尺度恢复和调制 | 根据历史与时间调整参与 | 选择历史、阈值和衰减在什么任务中有帮助 |
| 重放与局部教学 | 较长依赖仍获得有效学习信号 | replay、辅助目标与最终任务目标怎样共同支持信用分配 |

这些联系是研究起点。一个意图可由多种机制支持，保留意图也允许替换机制；有些贡献只在组合中体现。具体推进可按任务与资源选择，无需先证明所有设想都可同时达成，也无需一次穷尽所有组合。

数字计算还提供矩阵乘、scan 和 packed kernel 等能力。预填充的批组织可结合函数依赖单独设计，与生物启发形成的架构问题一同考虑；定义、条件性推论和实测效果各自记录。
