# 带权消息架构的设计空间与取舍

希望获得哪些能力、为什么探索这些方向，见[研究意图与探索路径](design-requirements-and-architecture.md)；本页展开带权支线内的机制选择与取舍。局部教材定义函数，本页分析它们能提供什么支持，实际在何处采用则由[拓扑与实例](../../instances/README.md)绑定。

当前主干实例的实现入口是[三组主绑定](../../instances/hb-multiscale-weighted-message.md#2-两类记忆与三个主候选)：K 全用 KV／sum，S 全用 SSD／state，X 在普通节点用 KV、hub 用 SSD。评分使用共同编码与区域 self_attention；分配主对照收敛为 received 下界的角色 quad、同边界 Shannon 与 pool，完整采用见[主干比较](../../instances/backbone-comparison.md)。参数使用[独立、区域共享、层级共享三档](../../instances/parameter-profiles.md)。下文保留更广的可选设计空间，供具体问题需要时展开；主候选也无需穷举所有组合。

本文从整体阅读局部架构：哪些信息被保存，哪些量参与评分与发送，哪些计算能省去，以及改变依赖可能得到什么、失去什么。共同定义见[局部架构](../../local-semantics/weighted-message/architecture-learning-note.md)，分配见[区域教材](../../local-semantics/weighted-message/region-allocation-learning-note.md)，记忆分别见 [KV](../../local-semantics/weighted-message/kv-memory-learning-note.md)、[基础循环](../../local-semantics/weighted-message/recurrent-memory/affine-delta-learning-note.md)、[Gated DeltaNet](../../local-semantics/weighted-message/recurrent-memory/gated-delta-learning-note.md)与 [SSD](../../local-semantics/weighted-message/recurrent-memory/ssd-learning-note.md)。

局部选择与拓扑共同支持研究意图。例如，传播摘要既依赖聚合和记忆，也依赖收集与发送到哪些位置；让 hub 在正接收时持续参与，可以通过单节点区域的既有约束分配，也可以通过共同区域中的角色边界实现。同一意图因此有多种构造，某项局部机制的作用需放回完整绑定判断。HB／LH 的具体安排及替代方案见[主干候选的形成与取舍](../../instances/backbone-design.md)。

数学性质提供设计边界，机制分析提供选择理由，任务表现仍依赖完整模型与训练。一个值得保持的研究判断是：保留任务需要的内容与历史依赖，同时减少一个量兼任多个控制作用的情况。它可以随实验结果逐步加强、减弱或修改。复杂耦合、计算成本和失败配置可能使某些判断长期无法被独立检验；未检验不等于已证伪，也不等于已验证。

表中的能力对应已定义函数；优势与困难是由信息和导数结构作出的机制分析。整网性质的充分条件见[共同组合定理](../../local-semantics/weighted-message/architecture-learning-note.md#6-数值性质的组合)，各发送函数的适用范围见区域教材 §7—8。外部实验依据集中在第 8 节，具体比较与观测由研究问题文档负责。

## 1. 从整体看各个选择

先选择[全连接分层](../../topologies/fully-connected-layered.md)、[HB-Lattice](../../topologies/hb-lattice.md)或其他合法图，确定谁能向谁发送、何时汇合，以及哪些节点共同选择。固定一次区域作用，候选节点 $v$ 的旧状态为 $q_v$，接收聚合为 $(r_v^{\mathrm{in}},u_v)$；Upd 得到新状态 $\widetilde q_v$。全部候选保留这次更新，描述模式选择 Describe 所读的状态：Read$^+$ 取新状态，Read$^-$ 取旧状态，Read$^0$ 取初态。

记忆模块从所选状态取得 Mem 四元组，并提供当前内容特征 $p_v(u_v)$。Describe 使用它们形成局部评分 $s_v^{\mathrm{loc}}$，并按所选发送函数提供区域证据或节点增益相关量。原 att 还需要当前内容投影与记忆 key；新 self_attention 使用共同编码向量，见 §4.5。

记截断接收量为 $w_v=\min(1,(r_v^{\mathrm{in}})_+)$。指定总量与区域阈值使用固定最大倍率的节点上限 $\mu_v^{\max}=\min(1,\gamma_{\max}w_v)$；区域汇集节点证据后，分别产生实际总量 $B$ 或共同阈值 $\eta_j$。节点增益与固定阈值分配等规则另使用逐节点增益 $\gamma_v$，得到 $\mu_v=\min(1,\gamma_v(r_v^{\mathrm{in}})_+)$，其上限或权重作用由发送函数决定。

围绕“区域决定发送强弱与激活规模、评分决定节点分工”的意图，当前采用指定总量、区域阈值、节点增益的阅读顺序：指定总量让总量头直接参与实际发送；区域阈值保留单位强度硬选择的配对目标；节点增益提供逐节点调节发送上限或权重的能力。这是依据依赖和梯度结构作出的设计判断，训练质量与实际成本仍待完整模型验证，取舍见第 3 节。

下面按计算位置列出选择，各行说明所用输入和产生的输出。Full 使用新状态；评分所读的状态由描述模式确定。

| 计算位置 | 输入与输出 | 在此处选择什么 |
|---|---|---|
| 接收 Agg | 完整来源消息 $\to(r_v^{\mathrm{in}},u_v)$ | 来源残差或同刻局部自注意力；分别选择参数共享，决定压缩前的来源处理与消息交互 |
| 记忆 Upd | 旧状态、当前接收 $\to\widetilde q_v$ | KV、基础仿射、基础 Delta、Gated DeltaNet 或 SSD；决定保存的状态与更新规则 |
| 记忆描述 Mem | 指定状态、当前内容 $\to$ 两个描述向量与两个统计量 | 时间摘要（sum）、KV 内容检索（qry）或循环矩阵查询（state），具体通道见 §2.2 |
| 节点描述 Describe | 当前接收、特征、Mem $\to d_v$ | encoded 复用一次节点编码；原 cat／match 直接形成局部评分，att 另给 key 与当前投影；证据仅在上下文控制时启用 |
| 区域评分 | 完整描述族 $\to(s_v)_v$ | ind 直接使用局部分数；原 att 用共同 query 匹配记忆 key；self_attention 让各候选读取其他编码并修正自己的分数 |
| 区域控制 | 接收加权的描述证据 $\to B$ 或 $\eta_j$ | 固定／上下文比例产生指定总量，或固定／上下文阈值；只用于相应候选 |
| 发送分配 | 所需评分及接收相关量 $\to(c_v)_v$ | 约束分配、直接 Attention、固定总强度 Attention、总量缩放 Attention、按比例分配或硬选择 |
| 完整计算 Full | 新状态、当前内容、正发送强度 $c_v$ $\to$ 逐边与逐端口值族 | 所选模块计算内容 $G_v$，广播载荷 $(c_v,G_v)$，决定下游的接收 |

例如“KV＋时间摘要＋拼接评分＋独立评分＋拼接区域证据＋上下文指定总量＋二次正则”选择了一套函数，再给定参数、初态和图即可形成完整模型。把时间摘要换为内容检索，改变 Mem 的取得方式；把独立评分换为区域 Attention 评分，要同时扩充 Describe 的输出与 SelStep 的输入；把拼接证据换为分组证据，保留证据向量的类型，改用独立的分组编码；把指定总量换为直接 Attention，保留局部评分，改用相应的节点增益描述和份额到 $c_v$ 的函数。各替换的类型与数值性质分别按共同架构检查。

节点增益描述的区域 Attention 可按 $\mu_v$ 或 $w_v$ 汇集 query；两个区域控制候选按 $w_v$ 汇集。配置名 mu 对应前者，received 对应后者；在直接 Attention 的份额中使用这两个配置值时，也分别表示这两个量。它们对增益学习通路的影响见 §3。完整运行可对照[全连接的两次输入](../../instances/fully-connected-layered-weighted-message.md#2-两层图上的两次输入)与 [HB 的分叉汇合](../../instances/hb-lattice-weighted-message.md#2-三层图上的分叉汇合与记忆)。

### 1.1 同刻消息在压缩前的合作

接收阶段新增的[局部自注意力](../../local-semantics/weighted-message/architecture-learning-note.md#23-同刻消息的局部自注意力)回应“在最终压缩前，让一条消息的加工取决于其他同刻消息”的需求。原来源残差随后也可通过记忆与 Full 的非线性形成共同作用；两种构造比较的是有限表示和计算预算下的交互方式，不是是否完全具有非线性。

新候选先以强度为先验逐消息读取，再作残差和来源非线性，最终仍压成一个 $u$。它可以让 Hub 背景影响细节加工，也适用于普通消息之间的一致、互补或冲突关系。信息是否抵达取决于拓扑；只有单条消息时没有消息间交互。它不预先保证学到有效摘要，也不无损保留来源。

这项计算位于准备阶段，收益须与实际到达数、成对读取、参数增量和快速通路时延一起比较。[完整绑定](../../instances/hb-multiscale-weighted-message.md#11-接收自注意力的完整替换)给出 64／128 轻量宽度、随 d 增长的加宽配置和三档参数归属；更深接收块、独立分组摘要及历史状态控制接收 Query 仍是可另行定义的方向。

## 2. 保存历史与分配信用

### 2.1 KV 与四种循环记忆

| 记忆 | 有利特性 | 限制与潜在困难 |
|---|---|---|
| KV | 当前 query 可以直接定位历史条目；旧条目保留各自身份；窗口与位置机制明确 | 存储与读取随有效条目数增长，有限窗口可限制这项增长；聚合及 K/V 投影已压缩信息，注意力也可能检索失败 |
| 基础仿射（affine） | 状态大小固定，输入决定系数，具有简单仿射复合 | 多条关联叠加可能干扰；基础绑定的表达与外部完整 SSM 有差别 |
| 基础 Delta（delta） | 预测误差驱动定向修正，便于理解和比较更新规则 | key 方向仍会干扰；仅有基础投影、门和读出 |
| Gated DeltaNet（gated_delta，简称 GDN） | 短卷积提取近期特征，L2 限制 Q/K 范数；保留门与定向误差修正共同管理历史 | 全候选执行卷积和矩阵更新；历史被压缩、覆盖，较 SSD 具有更复杂的转移结构 |
| SSD（ssd） | 每头标量转移适合专门分块算法；输入相关写入、读取与直通项提供不同通路 | 同一头的旧矩阵统一衰减；没有 Delta 的当前关联误差校正，步长同时控制遗忘和写入 |

Attention、SSM 与 Delta 都可从“怎样写入、保存和读取”来比较。结构化的状态更新、残差通路、并行算法、训练数据与数值设计共同影响结果；不能把这些模型相对一般 RNN 的表现归因于一个已经确定的原因。

KV 的历史条目允许直接匹配；循环模块通过当前矩阵读历史，过去的写入仍经过中间更新。仿射性便于重排求值，不自动保证长期梯度良好；状态压缩也可能提供有用归纳偏好。KV 保存的同样是节点接收到的聚合表示，不能由“逐条保存”推出原始输入可无损恢复。

GDN 沿用基础 Delta 的矩阵误差修正形式，另定义卷积特征、多头、具体门和输出变换；SSD 与基础仿射同样由旧矩阵的标量保留及当前外积写入组成，但写入系数、特征与读取有各自定义。对应关系在各教材的更新公式后说明。同一代数形式允许共用仿射复合依据，参数化和完整状态的差异仍会改变模型函数。

四种循环函数均有完整定义。外部原模型对应限于各教材附录列出的普通序列混合器、参数和开关；Tide 的接收权重、时间空档、辅助描述、区域分配及图结构仍需自己的训练依据。基础 Delta 与 GDN 可分别用于研究更新规则和包含卷积、门、输出变换的完整模块。

### 2.2 描述读取与 Full 读取

共同 Mem 接口返回 $(M_{\mathrm{short}},M_{\mathrm{long}},W_{\mathrm{short}},W_{\mathrm{long}})$。两个 $M$ 都有宽度 $d_s$，可接入相容的 Describe 构造，参与评分与发送控制。下表每一行对应一份记忆描述绑定，两个向量按所选行一起取得；各教材先定义候选向量，再显式组装这个四元组。

| 记忆与描述方式 | $M_{\mathrm{short}}$ | $M_{\mathrm{long}}$ |
|---|---|---|
| KV 时间摘要 | 窗口内按短期衰减汇集的摘要 | 窗口内不作时间衰减的摘要 |
| KV 内容检索 | 当前 query 对短期加权条目的检索 | 当前 query 对窗口内条目的检索 |
| 各循环模块的时间摘要 | 独立保存的短期接收摘要 | 独立保存的累计接收摘要 |
| 基础循环的矩阵查询 | 查询具有短期被动衰减的矩阵 | 查询无被动衰减的矩阵 |
| GDN／SSD 的矩阵查询 | 短期接收摘要 | 当前内容对一组多头矩阵的查询 |

在基础循环中，两份矩阵仍各自受到输入相关保留门的作用；GDN／SSD 的 long 通道也受所选门与被动衰减影响。两个 $W$ 始终按各自的时间规则统计接收写入量。其通道名称和数值不能直接解释为矩阵中可恢复的历史长度。

KV 时间摘要已有独立的摘要投影；内容检索则共享 Full 的 K/V 后再投影。共享可让内容与控制使用共同证据，也让评分反馈改变 Full 记忆。独立的小型描述 K/V 是合理的进一步候选：减轻控制读取成本、减少两项任务的参数冲突，同时增加写入和状态。采用前需定义新增状态、写入、窗口、读取、比较投影与继续；当前教材没有把它列为已经完整绑定的配置。

Read$^-$ 已可用于“当前内容查询旧记忆”，而 Full 仍读取本次写入后的状态。它移除当前写入到当前评分的那条路径，可能减少自匹配，也可能丢失有助于选择的最新证据。默认 Read$^+$ 保留这种证据。两种描述模式都在当前逻辑时间查询，使用的状态快照不同；未来状态依赖仍然存在。

矩阵查询保留当前内容到关联记忆的直接读取通路，selector 在每个候选上支付查询成本。改用时间摘要可以省这次查询，同时改变评分可获得的证据。

### 2.3 时间、门与梯度通路

Gated DeltaNet 分开保留门、误差写入门和输出门；SSD 的有效步长 $d_h$ 同时作用于保留比例与写入系数，输出门另外定义。它们都与发送增益 $\gamma$ 和发送强度 $c$ 分开。记忆可以影响区域评分及增益，区域选择则通过未来消息改变后续写入，整网依赖仍然存在。

固定本次输入特征时，GDN 对旧矩阵的线性系数为 $g(I-\beta kk^\top)$，SSD 为 $gI$，还各乘被动衰减。两者在本文门范围内的范数至多为 $1$，所以这条固定输入的递归通路不会逐步放大范数；乘积仍可能很快衰减。完整训练还包含投影、卷积、门、区域选择及图反馈，不能由这一局部界推出总梯度稳定。稳定 L2 与 RMS 在很小分母附近也可有较大导数，归一化常数是数值定义的一部分。

GDN 与 SSD 的短卷积按固定逻辑时间取槽，并以 $w$ 写入历史；这是保证弱事件消失时历史位置不跳变的一种具体选择。从空缓存开始、单位接收且接收间隔等于抽头间距 $\delta_{\mathrm{conv}}$ 时，它恢复普通因果卷积，在稀疏 HB 中则保留空档。只对“最近收到的若干条消息”做卷积可能更适合按事件计的任务，但定义的距离不同，且不能直接使用当前连续性引理。稀疏节点也可能很少有历史落在固定抽头上，抽头数、抽头间距与图时间需要一起理解。

状态大小固定只描述存储规模。Tide 的全部正接收候选仍执行矩阵更新与短卷积；全连接层不会因本节点未激活而省去这些工作。HB 若让整次下游接收缺席，才同时省去相应 Upd。比较实际成本需计入投影、状态带宽、Read、Full、图消息和硬件利用率，不能仅比较 KV 缓存与矩阵的元素数。

## 3. 一个量承担哪些作用

### 3.1 指定总量与区域阈值

两者都表达区域共同调节发送、评分决定相对分工。定义分别见区域教材的[指定总量](../../local-semantics/weighted-message/region-allocation-learning-note.md#2-指定总量的一次分配)与[区域阈值](../../local-semantics/weighted-message/region-allocation-learning-note.md#412-区域阈值分配)。相同的节点上限保护弱输入边界，相同的接收加权摘要提供区域内容与记忆证据；两者都只求一个总量乘子。

| 方面 | 指定总量 | 区域阈值 |
|---|---|---|
| 直接控制 | 给定 $B$，优化在该总量下分配 | 从全部评分减去 $\eta_j$，总量由优化求得 |
| 直接反馈 | 总量有余量时，改变 $B$ 必然改变发送总和；分支导数见教材 §6.2 | 总量约束松弛时有作用；被上下界固定时共同平移可被抵消 |
| 相对分配 | 给定 $B$ 后共同评分平移无效，相对评分决定分配 | 绝对评分和阈值共同影响总量与分工 |
| 零温目标 | 收敛到指定总量下的唯一线性最优分配，可有小数发送 | 单位输入与评分条件下可收敛到配对单位强度硬选择 |

直接总量的反馈路径便于解释，但任务边际影响相消、sigmoid 饱和和总量范围退化仍会抑制学习。仅有一个未饱和节点，即只有一个控制量严格位于零与其上限之间时，评分对该次分配的直接导数可为零，而总量导数仍非零。区域阈值对整个区域提供同一偏移；同时平移所有评分和阈值保持分配，参数的数值大小须结合这项自由度解释。

两者的下界为 $b^{\mathrm{recv}}=\min(1,\sum w_v)$，节点增益与固定阈值分配 constrained 使用 $\min(1,\sum\mu_v)$。前者允许放大上限提高而最低发送保持。比较完整训练时，要把这项下界差异与控制头的区别分别记录；两个区域候选之间可在相同上限和下界下比较。总量头可以在较低总量下调节，但当节点上限之和等于下界时仍无余量。

全连接单位输入保持 $w=\mu^{\max}=1$；若 $k>1$，两个区域头仍可能影响结果。若 $k=1$，总量被固定为 $1$，两个头均无调整空间。HB 可出现弱节点接收，具体余量和反馈按该次运行判断。一般弱总接收时，即使 $k=1$，两个区域候选也可能有非退化的总量区间。

正温度稀疏性与零温目标分别选择。两个候选均可使用 quad 或广义熵产生精确零，也可使用 Shannon／bern 持续混合。较低温度仍可能带来较大的过渡区斜率和较宽的饱和区；区域头没有消除这些性质。输入连续、局部梯度存在与训练效果良好是三项不同判断。目前没有训练结果说明哪一种区域控制更优。

### 3.2 逐节点增益

节点增益与固定阈值分配及其他使用节点增益的规则沿用第 1 节的 $w_v,\mu_v$。记 $M=\sum_{v\in C}\mu_v$，其中 $C$ 为本次区域候选集。直接 Attention 将评分归一化为份额 $p_v^{\mathrm{sel}}$，再取 $c_v=\mu_vp_v^{\mathrm{sel}}$；归一化所用的非负基权重可取 $\mu_v$ 或 $w_v$。下表固定当前接收、记忆特征和其他参数，只改变增益，比较它直接影响哪些量。表内省略节点下标。

| 组合 | 增益的直接作用 | 被保留或移除的学习通路 |
|---|---|---|
| query 按 $\mu$，直接 Attention 基权重为 $\mu$ | 改共同 query、改各节点评分、改份额、改本节点幅度 | 作用丰富，一个局部增益可影响区域内多个候选 |
| query 按 $w$，直接 Attention 基权重为 $\mu$ | 改份额及本节点幅度 | 移除增益经 query 改全部评分的通路 |
| query 按 $w$，直接 Attention 基权重为 $w$ | 通过本节点外乘 $\mu$ 改幅度 | 在当前局部求值中分开发送幅度与份额；失去增益协助竞争的能力 |
| query 按 $w$，节点增益与固定阈值分配 | 通过发送上限、可行域与下限影响分配 | $M>1$ 且节点上限局部松弛、正则不显含 $\mu$ 时，当前分配可能完全不依赖增益 |
| query 按 $w$，固定总强度且基权重为 $1$ | 无 | 增益可能整项不参与前向，应从该配置中省去 |
| 总量缩放 Attention | 通过 $M$ 和基权重 $\mu$ 改总量与份额 | 总量低时仍能按评分调配，保留接收与竞争的耦合 |

记忆影响增益和评分，区域共同决定实际发送；当前架构可学习记忆相关唤醒及节点分工。对“记忆决定唤醒、selector 决定分工”的更细分工，query 与份额都使用 $w$ 的直接 Attention 提供一份明确实现，但两个头仍共享输入证据与后续任务目标。

全连接单位输入实例逐节点 $w=\mu=1$，上述增益差别全部被截断；HB 的弱接收提供可辨别场景。减少依赖也可能使某项参数不再获得有效梯度，因此判断应同时看表达能力与反馈覆盖。

停止某条反传改变指定反向规则；改变 query 或基权重改变前向依赖，两者分别定义。

### 3.3 保障传播与内容决定放大

当前采用意图是：保障一定传播，同时让内容决定筛选与允许的放大。旧 $\mu$ 下界在 $\sum\mu\le1$ 时强制 $c=\mu$，这是可行集的结果，连续性并不要求如此。角色分配已有的 received 下界把保障系于接收，仍令 $c\le\mu\le\gamma_{\max}w$；正接收时总量为正、全体趋弱时控制趋零。它允许弱接收下重新分配和少用上限，代价是弱路径不再自动获得最大放大。最终端口是否持续输出还要看拓扑覆盖与各区的实际接收。

区间模式由评分、正则、阈值及边界共同确定总量；fraction 模式先用 $\rho$ 得到 $B=L+\rho(U-L)$，再在固定总量下分配。二者均是明确函数，没有额外的隐式决策者。直接总量头的好处是总量反馈清楚，代价是另设控制表示和参数；当 $L=U$ 时它没有作用。主实例保留区间模式和固定阈值，在强接收且 $k=1$ 的常见设置中不增加无调节空间的头。fraction 与更丰富控制继续作为按需候选，不另展开一套主配置网格。

## 4. 评分信息与分工

### 4.1 局部评分

局部评分先把当前内容、记忆描述和接收统计变为标量 $s_v^{\mathrm{loc}}$。先比较原有两个构造，§4.5 再说明共同编码：

| 局部评分 | 有利特性 | 限制与风险 |
|---|---|---|
| 拼接评分 | 小型单隐藏层网络，已含统计量与内容—记忆乘积 | 可能利用记忆长度或接收频率等捷径；各信息的尺度和用途需辨明 |
| 分组匹配评分 | 分组非线性、归一化及显式匹配，使各类证据的处理较清楚 | 相似度仍需映到执行价值；乘性交互和归一化都有优化取舍 |

拼接将各组放在不同坐标上；一次投影满足 $W[a;b;c]=W_a a+W_b b+W_c c$，各组可以获得不同权重。分组候选的差别来自合并前的独立非线性、归一化与匹配结构。match 自身也拼接编码结果；两种评分都含内容与记忆的交互。

### 4.2 区域证据

上下文区域控制需要节点提供向量，再按接收汇集，用于判断发送总量或共同阈值。[区域教材 §3.4](../../local-semantics/weighted-message/region-allocation-learning-note.md#34-区域证据)给出两种同型构造：

| 区域证据 | 有利特性 | 限制与代价 |
|---|---|---|
| 拼接区域证据（cat） | 从内容、统计与已有逐分量交互直接投影，参数与准备较少 | 只有仿射投影和输出归一化，缺少各组单独的非线性处理 |
| 分组区域证据（grouped） | 分别编码当前内容、记忆与统计，再组合各组及内容与记忆的匹配乘积；在区域汇集前提取节点内部关系 | 增加全部候选的描述计算；编码、归一化及输出宽度仍会压缩信息，训练优势待验证 |

两种证据均保留向量输出。局部评分相同的节点仍可能携带不同内容、需要不同计算量；用单一评分代替完整证据会提前丢失这些区别。区域汇集仍是有限宽度的加权摘要，分组编码本身不保证辨认所有跨节点的互补或冗余关系，也不排除模型过度依赖接收与写入统计。

评分、证据与增益分别绑定。拼接特征 $f_v$ 供 cat 评分、cat 证据与拼接上下文增益使用；选用 match 评分时，仅为仍使用它的部件计算 $f_v$。match 评分与 grouped 证据使用同一种编码构造，默认各有独立参数：前者学习节点分配的评分，后者向区域提供决定总量或阈值的信息。显式共享编码可减少重复工作，也会使两条任务梯度共同更新表示。

连续有界的两种证据均保持接收加权后的零边界，发送与硬化性质仍使用各自原有条件。更复杂的证据不会恢复约束已切断的反馈：当指定总量范围退化为一点，或区域阈值变化被总量约束抵消时，相应控制头仍可能没有直接梯度。现有拼接构造提供较简洁的参照，分组构造提供更明确的内部处理；二者的任务效果与实际成本需要完整模型验证。

### 4.3 区域评分与分工

区域评分随后决定如何使用局部评分。独立评分令 $s_v=s_v^{\mathrm{loc}}$；区域 Attention 评分另形成共同 query，与节点记忆 key 匹配，再和局部评分按指定尺度合成 $s_v$。

| 区域评分 | 有利特性 | 限制与风险 |
|---|---|---|
| 独立评分 | 描述小、准备较少；后续约束分配或归一化仍引入区域竞争 | 本地内容压成标量后，跨候选的关系表达有限 |
| 区域 Attention 评分 | 当前区域内容形成 query，比较各节点记忆；零发送但正接收者仍可影响共同 query | 单 query 有信息压缩，控制更耦合；未执行 Full 的具体反事实结果仍不可见 |

两种局部评分均可接入两种区域评分。更换区域评分时，节点描述随之增减当前特征与记忆 key；发送函数继续接收同型的最终评分族。

参数或私有状态的名字本身不产生分工。相同输入、参数和历史可保持对称；全连接同层通常更依赖私有投影与初始化差异，HB 的邻域已提供不同输入，同时可能导致暴露不均。

### 4.4 记忆 key 与统计信息

[区域教材 §3.6](../../local-semantics/weighted-message/region-allocation-learning-note.md#36-区域-attention-评分)给出两种 key，均用于与同一个区域 query 匹配，并可配合 cat 或 match 局部评分：

| 记忆 key | 所保留的作用 | 取舍 |
|---|---|---|
| 记忆与统计 key（content_stats） | 记忆向量与写入统计共同投影；统计影响可以随区域 query 变化 | 单次仿射投影较简单；记忆内容、统计与节点偏好共同影响匹配幅度 |
| 内容 key（content） | 独立非线性编码两个记忆向量，输出范数有界；显式统计仍可经已有局部评分影响最终评分 | 内容匹配与显式统计的路径较清楚；失去统计项直接随共同 query 变化的能力，增加描述编码计算 |

前一种构造中，将记忆向量拼接记为 $m_v$，两个对数写入统计组成的向量记为 $\ell_v$，投影矩阵按列分为 $U_v,V_v$；本段简记区域 query 为 $Q$。于是

$$
Q^\top K_v^{\mathrm{sel}}
 =Q^\top U_vm_v+Q^\top V_v\ell_v+Q^\top b_v^{\mathrm{mem}}.
$$

统计项的系数随 query 变化，模型可根据当前区域任务调整对接收积累的重视；也可能利用接收频率替代内容相关性。$W_a$ 是写入统计，尤其在循环记忆中，它不能精确表示尚存的有效信息量。偏置允许学习随 query 变化的节点偏好。

内容 key 配合非零 alpha_loc 时，显式统计保留在已有局部评分中，无需增设统计头。alpha_loc=0 关闭这项评分通路；这一结论固定 Mem 向量与 query，完整模型仍可通过记忆读取、query 权重、节点上限和区域控制依赖统计。两种 key 都含偏置，内容 key 的零输入也未规定为零输出。

Mem 已有自己的读取过程：KV qry 和循环 state 先由当前内容读取历史，Read$^+$ 还可纳入本次写入。因此内容 key 表达本次取得的记忆信息，通常不能只按持久状态缓存而忽略当前内容。独立 key 编码可与评分、证据采用相同的函数构造；参数共享与复用须另行声明。

内容 key 的归一化限制了 key 范数，query 范数和 alpha_sel 仍决定匹配尺度。归一化也会削弱幅度信息，其导数受分母和参数影响；范数有界不直接保证训练梯度适中。更清楚的依赖分工提供一种设计候选，训练质量仍需和完整计算成本共同评估；内容 key、局部评分与区域证据都属于选择前的准备。

分组匹配增益、将统计单独编码后仍放入 key、显式 Q/K 共同归一化，以及在 Agg 压缩前保留多个来源摘要，仍是待定义方向。采用内容 key 不要求同步改变其他部件。

### 4.5 共同编码与候选之间的关系

[encoded／self_attention](../../local-semantics/weighted-message/region-allocation-learning-note.md#37-共同编码与候选自注意力)回应两个问题：减少评分、key 和可选证据各自重复处理同一信息；让区域在决定份额前看到各候选之间的关系。节点先由 $f_v$ 得到有界 $z_v^E$，局部头保留自己的判断；区域每个候选产生 query，读取其他候选的编码，逐候选非线性后增加关系分数。可选的总量证据也能从该编码产生，但主绑定没有启用总量头。

旧流程为“局部网络给分、当前内容汇成一个 query、逐节点记忆 key 匹配”；新流程为“共同编码给本地分数、每个候选读取整区描述、关系修正后再分配”。原 att 的一次汇集较便宜，且可独立保留评分与 key 表示；新流程减少独立编码和配置，同时让一个候选的记忆直接改变另一个候选的评分。代价是共同表示可能成为压缩瓶颈，不同用途的梯度会共同改变它；成对读取还增加区域工作。没有依据认为共享表示或更强关系网络普遍更优，当前采用是结构与实现范围上的选择。

例如 A、B 提供近似内容，C 提供另一项相关证据。共同 query 可能同时偏爱 A、B；候选间读取给网络提供辨认重复与互补的机会。但同样的对称输入仍可能得到相同分数，逐候选打分也没有执行组合子集优化。它不能保证自动保留 C、打破 A/B 对称或预测未执行 Full 的真实收益。

这里沿用一层区域块、接收量先验和残差评分，保留 encoded＋ind 作为更轻的明确函数。Agg self_attention 处理“同一节点的多条消息怎样共同形成内容”，区域 self_attention 处理“同一区域的多个候选怎样形成评分”；二者既可互补，也可能重复投入。区域表示只用于选择，不传给 Full。因此它为分工与合作增加局部支撑，不承担传播全部信息的职责；连接、私有记忆及后续加工仍有各自作用。

## 5. 发送规则的取舍

发送函数使用接收相关量及所需评分，产生控制 $c_v$；正分量对应本次激活节点。约束优化先选指定总量、区域阈值或节点增益与固定阈值分配，再选择正则；下表的约束行比较正则本身，区域控制的区别见 §3.1。Attention 规则共用归一化份额，分别定义如何变为发送强度。按比例分配不使用评分，硬选择单独给出激活集合。完整函数与性质见[区域分配教材](../../local-semantics/weighted-message/region-allocation-learning-note.md#51-从所选函数得到完整返回)。

| 方法组 | 候选 | 有利特性 | 风险与成本 |
|---|---|---|---|
| 约束优化 | 约束 Shannon | 保持每节点上限和区域总量保障，持续混合 | 一般需求标量乘子；上限和总和约束可使评分反馈消失；执行全部有效 Full |
| 约束优化 | 二次正则约束分配 | 正温度精确零，过渡区斜率清楚，可省 Full 及下游工作 | 零或上限区直接评分反馈消失；低温过渡区陡峭 |
| 约束优化 | 广义熵约束分配，$1<\alpha<2$ | 精确零且接近零时响应更平缓 | 弱分量的恢复反馈也可能更弱；仍有截断与低温问题 |
| 约束优化 | 二元熵约束分配 | 非单点约束下有效候选在上下限之间，保留直接分配通路 | 全有效 Full 参与；极端占用比例的梯度仍小 |
| Attention 份额 | 直接 Attention | 无求根，保留每节点发送上限与弱输入连续性；可分开发送增益和份额依据 | 全有效 Full 参与；总强度可能逐层减小，微弱候选的反馈也可能很弱 |
| Attention 份额 | 固定总强度 Attention | 无求根，持续混合多个节点；弱线索可凭记忆获得较大份额；低总量仍有评分反馈 | 全部支持节点执行 Full；弱线索与噪声都可能触发单位总量，零输入边界按独立规则处理 |
| Attention 份额 | 总量缩放 Attention | 无求根，全区域趋弱时总发送趋零；低总量仍能依评分调配 | 可让单节点超过自身 $\mu$，放大某个弱来源；没有现成的整网硬化结论 |
| 按比例 | 按比例分配 | 保留发送上限与区域总量，提供不依赖评分的完整参照 | 全有效 Full 参与，分配本身不给评分网络反馈 |
| 硬选择 | 硬选择 | 每次严格限制激活数，工作上限明确 | 成员排序在严格间隔内局部不变，需要另行处理训练反馈与探索 |

稠密激活也可以形成内容与发送份额的分工，精确稀疏增加了跳过计算的能力。正控制量、非零局部导数和有效任务更新分别观察。更多信息的 selector 可能以当前准备换取更有价值的后续计算；总收益取决于消息出度、邻域重叠和任务。

当前主对照为 quad、约束 Shannon、pool。quad 与 Shannon 使用相同 received 下界和角色边界，便于比较正则及支持的变化；pool 保留无需约束求根的稠密参照，但同时改变总量与逐节点边界。group 分区只替换 D 区，H 区固定角色 quad。mixed 的角色 Shannon 可另行使用，角色保底恰好耗尽预算时，普通节点仍可能为零。其余候选保留定义与独立教学用途：广义熵、二元熵、直接／单位 Attention、比例分配及配对硬函数不进入当前主表，无需为保留旧方案强制新增实验基线。

对全区域 quad 或固定 $\alpha>1$ 的 ent，区域教材 §7.2、§7.4—7.5 分别给出相应条件下的正温度精确性。指定总量比较自身的唯一线性最优运行；区域阈值分配、节点增益与固定阈值分配比较单位输入的配对硬运行。所需温度依赖固定模型、输入和有限时间范围；训练改变参数，条件也会改变。固定温度、有限降温与零温部署的选择仍取决于计算量、反馈覆盖及任务表现。

共享 query 使这些函数都可具有跨候选依赖。固定上限与 keys 时，quad 对 query 是分段仿射，softmax 对 query 光滑；全网络的参数训练通常均非凸。这些局部性质不能排列整体“非凸程度”或训练难度。

## 6. 弱接收、触发与传播

“达到条件后发出较强内容”可以通过有界增益、记忆检索与区域分配共同表达。当前规则没有单独的膜电位、放电阈值与复位状态；KV 影响评分或增益并不自动等同于这套特定动力学。若任务需要静默积累、阈值触发和复位，可以另定义含这些状态的 Upd／Read／Next；需明确接收和无输入时的行为。

区域教材 §8.2 中满足发送上限的有界增益发送，允许弱信号沿有限路径变强，同时保持零边界连续性。任意微小正输入立即归一化成单位发送则会破坏该边界。把 $\mu$ 除以 $\min(1,M)$ 会在 $0<M<1$ 时得到和为 $1$ 的上限族；若继续要求总发送至少为 $1$，所有新上限会被用满，接收整体趋零时仍发送一个单位。这与明确的阈值触发、历史积累有不同含义。

约束分配的下限同时提供非空与区域总量保障。两个区域候选按接收取下界；节点增益与固定阈值分配在低上限总量处强制使用全部上限，各自的退化情形见区域教材 §4.1。较大总量与较小节点上限可共同要求很多节点激活，单靠降温无法突破这个可行性限制。$b=\max\mu$ 或 $b=\min(1,M/2)$ 等其他下界未作为完整配置纳入教材；采用时须重新给出可行域、反向、传播与极限。

广播总强度还乘入出度。一个区域的强度范围合理，无法单独保证各下游都收到足量输入，更无法确定消息数或内容范数。实例中的传播定理使用了额外的连接覆盖条件。

## 7. 状态、拓扑与可判断的范围

默认接收驱动写入、全部候选保留更新、Next 不读取 Full、区域历史为单点，已经使若干依赖清楚分开。这些约定保留未来反馈机会；未来是否读取、是否在反向截断内使用，以及上游是否持续提供输入，仍决定实际信用。

固定图上的选择改变当前计算路径，空间边在其他输入和历史中仍可用。全连接层中所有节点继续准备；HB 可因上游不发送而省去部分下游节点的整次作用。在[当前 HB 实例的单位入口与非空发送条件下](../../instances/hb-lattice-weighted-message.md#31-每个区域都有正发送)，每个输入位置仍到达全部区域，区域内节点覆盖由实际发送决定。收拢会缩短某些路径的分离时间，可能有利于纠正早期选择，也可能稀释局部差异。

记忆的保存与读取、Full 的内容变换分别承担职责。KV 教材的读取残差尺度为零时，Full 只用当前内容及前馈残差，描述读取仍可使用 KV；删除写入或改变 Attention／FFN 排列则需要完整的新函数绑定。不同区域怎样搭配这些计算，应按任务依赖与总成本选择。外部架构提供可行例证，不能单凭相似排列推出 Tide 广播与选择更优。

研究记录可以写“当前更倾向某组合，依据是这些可观察结果，尚有这些替代解释”。不必为每个直觉预设一整套隔离实验。需要安排具体实验时，另查[可选研究问题与对照](../training/weighted-message-research-questions.md)，优先级由研究者结合整体掌握和资源决定。

GDN 的部件消融采用 $400$M 参数、同一 FineWeb-Edu 子集的 $15$B token。头宽 $128$ 的完整模型平均困惑度为 $27.35$，去短卷积为 $28.95$，去输出门为 $29.12$；平均常识准确率分别为 $47.26,46.16,45.46$。这支持把这些部件纳入一个可核对的完整候选，也显示基础 Delta 公式不足以承接原模型的效果声明。

同一论文的真实检索任务中，纯循环模型仍有相对 Transformer 的差距，加入滑窗 Attention 的混合模型改善部分结果。其吞吐比较也显示短序列上的 FlashAttention-2 Transformer 可有优势。故 KV、GDN、SSD 及按区域混合都有保留理由；长期检索、推理状态和训练吞吐的取舍由任务与完整实现决定。仓库的[位置、注意力与记忆调查](../../../30-technical-notes/attention-position-memory.md)汇集更广泛的结构和研究比较。
