## 阶段与交付

1. **基线与边界。** 核对工作区、上游、配额、活动任务、资源及用户文件；冻结源码/配置。
   分开首个主干输出、完整 prompt 就绪、首增量、稳定增量和持续吞吐；冷启动单列。
   连续流保留 pending，仅有限流终点 flush；输出可消费释放，旧分段 flush 身份保留。
2. **接收 self-attention。** 三种 incoming 配置正式覆盖公式、梯度、更新、续接及恢复。
   有界比较融合 QKV、静态 padding 掩码、相容合批、普通/native/tiled 路径和局部重算。
   保持节点私有参数/状态、真实零质量导数；不混不同接收者的 Attention 轴。
3. **FP32 共性热点。** 优先完整矩阵 SSD 传播/扫描与单位置递推；再检查 allocation、
   索引及 Full packing。独立公式和局部同函数验证后，测完整训练/推理；保留原候选。
4. **大参数常驻推理。** FC-K、HB-X 约0.5B/1B及一组中大 Settle/Timed；9B/17B HB
   补首输出、缓存增量和批量流式吞吐。重新选择推理卡数，比较同卡合批、区域跨卡并发
   与传输；预算覆盖真实余量，allocated/reserved分开记录。
5. **四类对照与双边归因。** 每 Agg/正式负载按[联合契约](benchmark-contract.md)
   重审计实际活跃目标并冻结 A–D。双方有限调节块粒度、缓存、Attention及多卡放置。
   至少一个中大 FP32 点有正常计时、阶段诊断和设备轨迹；重叠时间不拼成占比。
6. **完整验证。** 三种接收都有真实多步/恢复；主力入选 FP32 组合约100更新。
   推理跨缓存填满与淘汰，主测约256增量调用；验证状态、原始时间、分块和有限值。
   原阈值/失败保留，有限差异有界调查；完成受影响测试、集成与安装检查。
7. **分模式推荐。** 训练、首输出、单请求增量、批量推理各自给配置、证据与复现入口。
   实现先提交冻结，正式资格另记；阶段提交/推送，更新导航、经验和最终交接。

## 有限矩阵与停止边界

| 范围 | 代表选择 | 边界 |
|---|---|---|
| 小型诊断 | 当前 FC/HB；四种 Agg | 独立公式、全部相关根梯度、路径/时钟 |
| 主力规模 | FC-K/HB-X 约0.5B/1B；Settle/Timed代表 | source_residual/light64 主线，light128/wide补点 |
| 大容量 | 约9B/17B HB | 实际参数重计，常驻推理和资源对照 |
| 首输出 | B1，prefill 128/512/2048中可行代表 | 少量chunk候选；完整prompt与首个输出分开 |
| 持续推理 | 单位置增量及多位置chunk，有限batch阶梯 | 缓存真实续接，尾部单列，输入位置作分子 |

先筛选再做正式 A–D，不对所有试验组合重复完整矩阵。每个热点至多少量有依据候选；
按预设候选数、时间、内存和收益停止。OOM、预算停止、内层失败和不稳定测点原样保留；
它们不是性能资格。不同模型计算量差异是工作特征，不要求 Tide 必须追平 Transformer。
