# 四类联合匹配与性能口径

本页是已确认的比较目标；实施计划在 [ROADMAP](ROADMAP.md)，已有结果在
[FP32 报告](evidence/instances-fp32-20261118.md)。新的联合匹配、实际触及统计、精度和
计时入口见 [比较设施](benchmarking.md)。设施可执行与正式资格分别记录；已有单轴
结果保留原身份，新源码的实测范围仍以 STATUS 和固定证据为准。

## 同时匹配两个约束

| 类别 | Transformer block 数依据 | 参数目标 |
|---|---|---|
| A | 接近 Tide 节点/局部 block 总数 | 接近总参数量 |
| B | 接近 Tide 节点/局部 block 总数 | 接近声明口径的实际活跃参数量 |
| C | 接近 Tide 区域层数/串行深度 | 接近总参数量 |
| D | 接近 Tide 区域层数/串行深度 | 接近声明口径的实际活跃参数量 |

每类同时满足两个近似约束。优先选定 block 数，再选择合理的宽度、头和 FFN 尺寸匹配参数。
记录目标值、实际值、偏差及选择理由；最近合法点无法精确匹配时如实说明。
仅固定宽度、改变 block 数匹配参数，不构成这四类联合匹配。无效参数不参与凑数。
K/S/X 节点不是同一种 Transformer block；Timed 还报告实际作用次数，空间深度不能
替代展开后的工作量。另加同宽度等单轴对照时，清楚标为辅助观察。

已有 FP32 数据主要是同宽度、近总参数量及少数节点/层数单轴对照，不能追认成新矩阵。
Transformer 与 Tide 数学不同，不能据此比较模型质量。FC-S 保留 SSD 参考；有意义时
增加同函数直接实现，前者与后者的正确性含义分别说明。

## 参数与工作量

1. 总参数从实际唯一 Parameter 统计，注明主干、入口投影及其他边界的计入范围。
2. 保留教材的活跃代理：共享基座、区域网络与私有参数按主绑定公式计算。
3. 四类主表中的活跃量以明确定义的实际有效触及量为主，覆盖接收、准备、区域和 Full；
   按样本与逻辑时刻声明共享去重范围。先用小型独立枚举验证统计。
4. 另列候选更新、Full、消息、查询/键、padding、重复矩阵运算和内存搬运；参数去重
   不会消除重复计算，实际访问量也不等于 FLOPs。

Timed 记录每逻辑时刻及每输入位置归一化的累计工作，不凭一次轨迹推断输出因果归属。
建立匹配时固定输入、初态、参数和运行模式；训练后的活动变化另列，不在计时中更换基线。
记录上游代理与实际量的差别。`k/n` 是发送强度预算比例，不是硬活动数量上限。
人为构造的稀疏压力用例与常规初始化分开报告，不能冒充训练获得的稀疏性。

## 精度、模式和边界

FP32 与 BF16 各自做同精度对照，再比较精度切换。实际计算和累加策略见
[precision](precision.md)，不把 BF16 前向称为所有状态均为 BF16。

区分无梯度推理、记录图的前向和完整 AdamW 训练。后者包括必要准备、packing、loss、
反向、通信、更新与同步。记录输入传输、模型构造、缓存预热和 checkpoint 是否计时。

prefill 吞吐用实际输入位置数/秒。decode 使用真实历史和增量缓存；分别报告首个主干
输出可用时延、稳定 decode 时延与吞吐。Timed 的输入窗口及完整 flush 分开并合计；
padding 容量、逻辑 tick 数和消息数不能充当输入 token 分母。
没有任务头时，主干首输出不是完整语言模型服务 TTFT。

## 可信且有限的测量

先检查基线自己的批量粒度、缓存和算子选择。配对输入、初始参数与计算边界，记录哈希、
源码/测量设施提交、实际精度、执行位置、算子路径、资源争用、样本和峰值内存。
跨设备训练可能改变后续路由；有这种差别时说明实际工作，不能称严格同轨迹加速。

正常计时与侵入式诊断分开。短任务在一次独立流程内充分预热和采样；只有变化、失败、
噪声或具体未决问题要求时重测。共享设备测量仍是共享观察。
CPU 线程和 affinity 按代表负载有限校准，不把权限上限当最优线程数。

报告分清数学必要成本、额外计算、调度/计算图成本及未解释部分。性能结论限于实测配置，
不设必须追平 Transformer 的门槛；结束时应有可复现结论和具体剩余问题。
