# Tide：从 Transformer 的残差走向局部网络

面向熟悉 Transformer、首次接触 Tide 的听众。主线是 **Transformer → 展开 MoE → 完成一次计算 → 局部网络 → 引入历史 → 回看接口与代价**。[研究意图与探索路径](../../memos/design/design-requirements-and-architecture.md)保存研究缘由与机制取舍；[展示材料](README.md)提供离线 HTML、PDF 和逐停点备注。屏幕文案和具体讲解维护在 [content.py](content.py)，本页只保存叙述设计，避免重复维护整套备注。

## 1. 从已有计算看节点边界

首屏直接画一个 pre-norm Transformer block：两次 Norm、Attention、FFN/MoE、两条残差旁路及两个 Add。原始 post-norm 版本的 Norm 位置不同，首次展示先固定这一种结构。

一个节点可以容纳完整 block，也可以只表达 Attention 或一个 expert。粗粒度封装让内部 Add 随计算一起保留；细化后要把原先藏在边界内的职责重新画出。这里不以节点粒度推断去中心化程度。

随后只展开 FFN/MoE 位置，以 $x$ 表示该位置的残差基线：

$$
\text{专家贡献 }E_i(x)
\quad\longrightarrow\quad
r=\sum_{i\in A}a_iE_i(x)
\quad\longrightarrow\quad
y=x+r.
$$

专家可以包含支路的 Norm。每个专家保留一个节点；区域 SelStep 负责选择与控制；M 的 Agg 区分基线和贡献并求和，Full 执行 Add。基线沿显式旁路传递。局部 residual 不要求整网共用唯一主干。

## 2. 尽早走完一次计算

采用新增的[显式残差 MoE 教学绑定](../../instances/explicit-residual-moe.md)，不从旧 HB 的 $G=u$ 特例推断专家行为。

| 停点 | 新增理解 |
|---|---|
| 3.1：选择 | $x=2$；评分 $(2,1,0)$；Top-2 选择 $E_1,E_2$，所选权重 $2/3,1/3$ |
| 3.2：贡献 | $E_1(2)=4,E_2(2)=-2$；加权后发送 $8/3,-2/3$；第三个专家不执行 |
| 3.3：合并 | 旁路与贡献同在时间 $3$ 到达；$r=2,y=4$；图外不再重复 Add |

全场对这张图保持节点位置。蓝色表示载荷，金色虚线表示控制，深色旁路表示基线。未选节点保留轮廓和“不计算”说明；静态连接与实际消息要能区分。开始时全部状态为单点，不提前假定 KV 或其他历史。

完整函数、初态、容量、平分规则、空候选行为、时间与端口见实例 §2—3。[可执行核对](../../examples/explicit_residual_moe_checks.py)用按边求值和直接公式作比较。

## 3. 一个局部小组还不等于整个去中心化网络

从小组过渡到 HB 的有界邻域图。明确换了拓扑示意，尚未把前页的 MoE 参数嵌入 HB。单组内增加专家，会同时扩大输入分发、选择和合并范围；扩大网络需要多个有界组及组间连接，并检查是否所有路径仍绕回同一个固定内部主干或决策中心。

在此引出已确认目标：模型信息与决策局部性；任务效果可比时，优先减少参与节点、连接、完整计算和消息。经过全部区域可以接受；设备部署与学习规则另议。删去旧版单独罗列目标的第二屏，让需求出现在实际取舍旁边。

随后说明条件推论：固定输入输出端口数、单节点直接通信对象数有界，扩大输入到输出的可达容量，就需要增加多跳扩散与收拢。不同模型可以有不同有限端口数，分别考察固定配置。无界端口仅作 Tide 范围外的问答，不展开适配方案。

## 4. 明确切换到有状态扩展

新增专家节点本地激活计数 $q_i$，评分改为 $\ell_i(x)-3q_i$。每次 Upd 保持旧计数，Read$^-$ 读取旧计数，Next 根据激活指示加一，Full 仍只计算之前的专家函数。区域历史保持单点。

两次输入都取 $2$，固定当前内容以孤立历史的影响。第一轮 $q:(0,0,0)\to(1,1,0)$，输出 $4$。第二轮评分为 $(-1,-2,0)$，改选 $E_3,E_1$，贡献和为 $6$，输出 $8$；重置计数则恢复输出 $4$。计数是持久状态，当前表示 $x$ 是消息内容。这个选择惩罚只用于教学，不宣称它提高任务质量。

原 HB 的接收写入、KV/Read$^+$ 是另一种绑定，不沿用到此例。Mem/Describe 在历史用途已经清楚后再引入：一般 Read 足以读取计数；带权支线通过 Mem 从 KV 或循环矩阵取描述，再由 Describe 结合当前接收。区分一般接口和具体实现。

## 5. 回看接口、成本与上下层反馈

P/S/U/F 是每次区域作用的阶段，专家、router、合并、Add 是功能。用已完成的小图解释：专家 P 读描述、区域 S 选、U 确定两个状态快照、F 算贡献；M 也有全部阶段，其 P 求和、F 执行 Add。阶段与功能不能一一对应。

共同框架规定对象和依赖；拓扑规定连接与时间；局部语义给出函数；完整绑定再补上端口、初态、参数和读出。展示新例子的实际工作，而非借用 HB 的旧计数：

| 观察 | 新例子每次输入 |
|---|---|
| 候选准备／区域选择 | $5$ 个节点作用／$3$ 次选择（两次为单节点） |
| Full | 两次专家、一次分发、一次合并输出 |
| 内部消息 | 三条候选输入、一条旁路、两条贡献，共 $6$ 条 |
| 其他 | 两次权重乘法、一次贡献求和、一次 residual add；外部输入输出各一条 |

标量专家自身便宜，真实 FFN、查询和通信的成本要分别测量。上述次数说明计算结构，不能代替任务效果或设备加速证据。

上下层反馈沿四个问题收束：候选分发是否抵消计算节省；多个局部组是否仍依赖唯一主干；旁路外显后增加什么对齐与通信；历史描述保留什么信息、花多少工作。主讲最后回到 Next Token 预测、单输入单输出实验，声明可比质量条件后再比较总工作。
