# 带权消息架构：实现与数学定义的对应

本文核对已选择的组合与数学定义是否一致。共同函数见[局部架构](../local-semantics/weighted-message/architecture-learning-note.md)，评分、分配和反向见[区域分配](../local-semantics/weighted-message/region-allocation-learning-note.md)，组合性质见[共同架构 §6](../local-semantics/weighted-message/architecture-learning-note.md#6-数值性质的组合)，记忆定义由各模块教材给出。训练效果和研究优先级由[独立研究文档](../memos/training/weighted-message-research-questions.md)讨论。

## 1. 采用声明与比较对象

### 1.1 采用范围与模型绑定

实现记录不可变上游提交、核心语义版本、具体函数组合、图、时间、参数与状态表示。局部函数可以在同一核心版本下演进，定义由所采用的提交定位。列出支持的 memory_family、memory_read、read_mode、评分、region_key、region_evidence、query_weight、allocation_base 和 selection_mode，检查各键的生效范围及类型。名称迁移与采用记录见[版本对应](../records/semantic-versions-and-adoption.md)。

教材中的自由参数与函数选择确定模型族。一次核验固定具体绑定，保存可恢复参数、初态与输入的材料；维度、单位和参数共享关系也属于绑定。下游声明支持的组合及限制，可只实现其中一部分。数值约定另记录精度、容差、求根终止规则、下溢和裁剪，以及不可微边界的反向约定。

采用实例中的配置时，按其最终绑定表确定各区域的函数选择，再核对所选状态、初态、Upd、Mem、当前特征与内容函数。KV 的窗口和旋转参数只用于 KV 区域。指定总量与区域阈值按 ind／att 使用四元组／六元组描述；使用节点增益的规则按 ind／att 使用三元组／五元组。按所选描述给定匹配及证据构造；$f_v$ 的三个使用者为 cat 评分、cat 证据和拼接上下文增益，各自采用独立参数。match 评分与 grouped 证据使用各自的分组编码，均不依赖 $f_v$。

### 1.2 比较对象与适用条件

选定函数后，按所要核验的关系选择比较对象：

| 比较 | 必须保留的对象 |
|---|---|
| 参考递归与同一函数实现 | 完整 P/S/U/F 作用支持、结果、快照、持久状态、逐边与逐端口值族 |
| 联合求值与逐次求值 | 上述记录及右切面，包含在途消息和原始时钟 |
| 精确零消息的增删 | 共同架构命题 1 声明的消息投影、有效状态与读出；原始事件支持可不同 |
| 弱输入的极限 | 共同架构命题 2 声明的消息投影、有效状态与读出 |
| 指定总量与自身零温分配的极限 | 固定参数、有界输入、有限切面，每次零温线性最优解唯一；保留同一总量头与小数发送 |
| 区域阈值分配、节点增益与固定阈值分配各自的硬化 | 固定参数、单位输入、有限切面、配对硬运行评分条件下的数值投影；区域阈值保留同一控制头 |
| quad／固定 $\alpha>1$ 的 ent 的正温度精确性 | 在所选极限的条件及充分小正温度下，比较实际作用支持、全部作用结果、原始状态和完整切面 |
| 反向实现 | 声明的精确解映射、显式分配或另行指定反向的向量—Jacobian 乘积 |

有效状态投影可以遗忘过期项或不同时间戳，不能替代精确状态解码。数值试验核对实现，命题的一般性由证明给出。候选、控制正分量、Full 调用和消息数分别记录。

组合合法性核对类型、容量、依赖与时间条件；连续性、硬化等性质另核对各自的前提。例如固定总强度 Attention 可以组成模型并精确继续，弱接收连续性一般不成立，见[区域分配 §8.1](../local-semantics/weighted-message/region-allocation-learning-note.md#81-零接收与正温度连续性)。验收结论须指明所采用的函数与所核验的性质。

### 1.3 从定义到验证证据

下游为每项已采用、可独立核验的语义要求维护对应记录，使读者能从固定版本的定义找到配置、代码、测试和运行结果。每条记录包含以下内容，可引用共用的模型配置和数值约定：

1. **数学定义。** 上游提交、文件及章节或公式，所选候选、需要核验的关系及其适用条件。
2. **配置与代码。** 配置怎样绑定函数与参数，具体实现的文件和符号入口。对应覆盖参数形状、单位、共享关系、初态和状态字段，区分旧状态、候选状态、计算快照及下一状态；返回值按数学字段、元组次序及缺席含义对应。使用其他表示时，给出[解码与投影](semantic-interface-index.md#附录实现对应的验证关系)的入口及含义。
3. **测试。** 可定位的测试用例、前提、具体断言和预期结果的来源，说明比较哪些字段、支持集或投影，以及精确相等或数值容差。预期结果由手算、独立参考计算或已证明关系确定；复用被测函数计算预期值时，须说明该测试能独立核验的范围。反向测试另声明求导目标、求导变量、共享依赖和边界约定。
4. **运行证据。** 实现与测试的版本、构建和依赖版本、配置、参数与输入材料、后端及精度、复现命令、结果文件与误差。实际运行含未提交改动时保留对应差异。结果注明通过、失败及未覆盖范围，使同一测试的不同运行可区分。

对应记录提供双向定位：数学条目可查到代码与测试，代码与测试可经该记录回到固定定义，测试条目可查到实际运行结果。函数可以拆分、融合或共享实现；记录须说明其数学对应及结果如何恢复。同一测试可以核验多条要求，逐条列出实际断言即可。文件组织与记录格式由下游选择。

逐次求值、联合求值、反向和不同设备实现分别标明已核验范围。只有声明范围内的绑定、代码、测试和运行证据齐备，且满足相应比较关系时，才报告该范围通过验收；其余明确记为未实现、未验证或条件不适用。

本仓库维护定义、比较关系与核对要求；实现仓库维护具体对应记录和运行证据。[采用记录](../records/semantic-versions-and-adoption.md#下游引用)保存下游对应入口。

### 1.4 Read⁺ 的对应示例

以[共同架构 §3.3 式 (8)](../local-semantics/weighted-message/architecture-learning-note.md#33-节点描述与状态快照)为定义入口，固定所选记忆模块、Describe 及其参数，配置取 read_mode=+。给定旧状态 $q$、时间 $\theta$ 和聚合 $h$，应有

$$
\begin{aligned}
\widetilde q&=\operatorname{Upd}_v(q,\theta,h),\\
d_v&=\operatorname{Describe}_v[\operatorname{Mem}_v,p_v]
       (\widetilde q,\theta,h).
\end{aligned}
$$

下游记录配置解析、准备阶段传入快照、所选 Upd、Mem、$p_v$ 与 Describe 的代码入口，以及状态和描述字段的解码关系。这个对应须能确认调用使用的是 $\widetilde q$。

测试取描述确实依赖记忆的参数，构造旧状态、候选状态和初态能给出不同描述的输入。由独立参考计算得到 $\widetilde q$ 与 $d_v$，核对候选状态及完整描述返回。若还支持 read_mode=-／0，在相同时间、聚合与参数下分别按旧状态和初态求预期值；测试应能发现快照误用。

状态保留另按共同架构 §3.1 核验：当所选发送函数允许正接收候选不激活时，构造已写入但未激活的候选，断言其下一状态仍为 $\widetilde q$。记录分别链接描述读取和状态保留的测试及运行结果，注明配置、参数材料和误差。它们核验这两项要求，完整 Full、联合求值及继续仍按各自条目核验。

## 2. 共同函数

| 核对项 | 覆盖情形 |
|---|---|
| Agg | SrcClass 的带标签端口／入边定义域、完整纤维、来源、平行原子、空输入和零强度；同类别的不同原子各参与一次；同参数面对不同邻域仍分别求值 |
| Read 与描述 | Describe 绑定所选 Mem 与 $p_v$；Read$^+$／$^-$／$^0$ 向 Describe 分别传入新状态、旧状态和初态，并保留当前时间与聚合；描述宽度与区域 SelStep 相容 |
| Next | 所有候选保留接收更新；未激活也保留；不得读取或重算 Full |
| SelStep | 空候选、全零接收、单候选；每候选都有控制；单点历史；$K$ 按所选函数绑定 |
| Full | 正控制才激活；$(c,G)$ 的强度只在数值投影中乘一次；返回边与端口两个族 |
| 广播与读出 | 出度不除分强度；端口记录保留身份；空读出、相消与正强度存在分别核对 |

采用节点增益描述时，增益检查 $1\le\gamma\le\gamma_{\max}$、$\mu=\min(1,\gamma (r^{\mathrm{in}})_+)$。query_weight=received 时，固定接收与记忆特征，改变增益不能改变 query；direct_attention 且 allocation_base=received 时，固定评分后只经外乘 $\mu$ 生效。query_weight=mu 的原依赖继续保留。

相同参数与输入的共享求值只记一次工作，仍须恢复各节点的原始状态。前向移除依赖与 stop-gradient 的反向约定分别检查。

## 3. 区域分配

### 3.1 约束分配

对实现支持的 quad、bern、Shannon 与固定形状 ent，按区域教材 §4.1 向 Alloc 传入各候选的评分、节点上限及总量范围。检查边界、互补条件和最优性；小规模可与独立求解或断点算法比较。覆盖单点可行集、全低分、总和上下界、松弛总和、零个或一个未饱和分量。constrained 另核对 $M=1$ 两侧及 $M\le1$ 的全上限分支。

求根区间、乘子符号、残差与误差分别报告。区间构造使用 $x_v^{\mathrm{bracket}}$；Newton 导数在当前迭代点求值，精确解映射的反向在最优响应点 $x_v^{\mathrm{resp}}=t_v-\lambda$ 求值。softmax 等值按[区域分配 §5.6](../local-semantics/weighted-message/region-allocation-learning-note.md#56-与-softmaxsparsemaxentmax-的关系)核对：区分对任意评分成立的单位上限条件与给定评分的可行性判定。覆盖非单位上限但 softmax 可行的算例，以及触及、超过上限时的前向与边界反向。ent 的 $\alpha=2$ 在总和可变时核对阈值移位。

### 3.2 指定总量与区域阈值

正温度的两个候选使用同一 Alloc：指定总量见[区域分配 §2.2—2.4](../local-semantics/weighted-message/region-allocation-learning-note.md#22-由节点特征确定发送总量)，区域阈值见[§4.1.2](../local-semantics/weighted-message/region-allocation-learning-note.md#412-区域阈值分配)，共同求解见该教材 §6。按以下依赖逐步核对：

| 步骤 | 核对内容 |
|---|---|
| Describe | $\mu_v^{\max}=\min(1,\gamma_{\max}w_v)$；区域证据按区域教材 §2.2、§3.4 使用当前接收及所选 Mem，cat 另使用 $p_v$ 的乘积特征；fixed 返回零证据，context 绑定 cat／grouped 的全部参数 |
| 汇集与控制头 | 按 $w_v$ 汇集证据，分母为 $\max(1,W^{\mathrm{recv}})$；att 的 query 同样按 received；零接收证据对汇集无贡献 |
| 总量范围 | $b^{\mathrm{recv}}=\min(1,\sum w_v)$、$U=\min(k,\sum\mu_v^{\max})$；覆盖 $b^{\mathrm{recv}}=U$、节点截断及弱总接收 |
| regional_total | $B=b^{\mathrm{recv}}+\rho_j(U-b^{\mathrm{recv}})$，传入 $t=s,[B,B]$；求解乘子可为任意符号，共同评分平移不改变控制 |
| regional_threshold | $t=s-\eta_j$，总量范围 $[b^{\mathrm{recv}},k]$；固定其他输入，提高阈值使总发送单调不增 |
| 配置与状态 | 两者不使用 send_gain、allocation_base；regional_total 不使用 eta；正温度容量取区域大小，无新增持久状态 |

证据构造核对下列内容：

- cat 保留原拼接投影；grouped 的三组输入、编码宽度、四个输出矩阵及匹配乘积按区域教材 §3.2、§3.4.1 对应。局部评分与证据可交叉选择，描述字段和输出宽度保持相容；fixed 不执行证据编码。
- 固定输入与记忆描述时，独立改变证据参数不得改变评分，独立改变评分参数不得改变证据。显式共享编码时，前向使用同一绑定，反向汇总各使用者的梯度。
- 两种证据都满足 $\|z_v^{\mathrm{reg}}\|\le\sqrt{d_{\mathrm{reg}}}$；接收趋零时检查 $w_vz_v^{\mathrm{reg}}\to0$，包括内容方向改变或记忆描述不收敛的序列。精确零接收候选的增删不改变汇集结果。
- 在不跨接收截断与总量分支的输入上，对编码参数、当前内容、记忆与统计量作方向差分，核对经证据、汇集、区域头到发送的完整反向。分组构造的归一化与乘积也须参与；总量范围退化或阈值被约束抵消时允许控制路径梯度为零。

按[配置表](../local-semantics/weighted-message/region-allocation-learning-note.md#s1-配置名称)另核对 regional_total_zero 与 regional_threshold_hard：保留对应 Describe、评分和区域头，直接执行区域教材 §4.4.2、§4.4.3 的配对函数。前者保持总量 $B$ 和区域大小容量；后者以 $k_j$ 限制激活数。两者与 hard_selection 均不读取温度或正则，不调用正温度求根器；覆盖全零接收、平票次序及非单位上限。一般非二元接收下，区域阈值硬函数未必保持 $b^{\mathrm{recv}}$，按其自身函数核对。

复现区域教材 §2.5 的指定总量计算、§5.2 的阈值比较和 §5.3 的弱接收例子。首例使用 §3.4—3.5 的证据投影与区域头参数，核对证据变化到 $B$ 及分配的完整计算。两个候选不能套用 constrained 的“$M\le1$ 返回全部上限”捷径；全上限分支由实际下界等于节点上限之和判定。单节点也可能在 $b^{\mathrm{recv}}<U$ 时由区域头改变发送。$k=1$ 在弱总接收时未必消除这项余量。

反向把响应输入 $t$、节点上限 $\mu$ 和当前等式总量 $T$ 先作为独立变量，再回传其依赖。指定总量在非退化分支核对 $dc_v/dB=a_v^{\mathrm{resp}}/\sum_u a_u^{\mathrm{resp}}$，并对 $B$ 的下界、上界及比例使用完整链式法则。区域阈值核对总量约束松弛时 $dc_v/d\eta_j=-a_v^{\mathrm{resp}}$，总量固定时该项为零；起作用的接收下界仍须回传。头、证据、接收、评分与记忆的共享输入贡献相加。

用不跨分支的方向差分核对完整导数。复现区域教材 §5.2、§6.2 相同前向 $(1,0.4,0)$ 下不同的总量、阈值和评分导数；同时检查零个／一个未饱和节点、比例端点、sigmoid 饱和、min 边界与单点可行集。$\sum a_v^{\mathrm{resp}}=0$ 时不能使用除法公式。

### 3.3 Attention 份额与发送

| 规则 | 核对内容 |
|---|---|
| direct_attention | 两种基权重；$c\le\mu$；正接收全激活；单候选达到自身上限；不使用 k、eta、正则 |
| unit_attention | uniform 按真实候选，mu 按正接收；有支持时总和 $1$；允许 $c_v>\mu_v$ |
| pooled_attention | 总和 $\min(1,M)$；允许单节点超过 $\mu_v$；全部接收趋零时总发送趋零 |

复现区域教材的弱接收算例、评分平移、候选置换、全零分支、很小正权重和大评分差。数学上的正支持不能以浮点下溢或近零裁剪代替。uniform 区分真实零强度候选与张量填充位置。

### 3.4 按比例分配与硬选择

按比例分配核对总和 $\min(k,M)$、节点上限和全零分支；保持 $\mu$ 不变时，改变评分不改变分配，也没有分配到评分的直接梯度。

硬选择核对稳定平票顺序、零接收排除、全非正时最高分保留与激活上限。硬函数的训练替代梯度属于独立声明。

### 3.5 反向与边界

约束分配使用区域教材 §6.2 的隐式反向，或者明确声明有限迭代映射。光滑分支内用不跨界的扰动比较评分、上限和温度；总和固定在上下界时核对加权中心化，总和上下界都松弛时核对独立响应导数。复现该节 quad 的共同评分平移算例；$\sum_v a_v^{\mathrm{resp}}=0$ 单独处理。不可微点用声明的单侧或广义导数核对。

一个响应点核对例子是 quad、$\mu=(1,1),k=1,t=(0.6,0.4),\tau=1$。此时 $\lambda=0,c=(0.6,0.4)$，实际响应点为 $(0.6,0.4)$，区间构造点为 $(0.5,0.5)$。固定评分和上限，精确解的温度导数为 $dc/d\tau=(-0.1,0.1)$。

Attention 规则分别检查 $dp$、外乘幅度或区域总量的乘积法则。对 direct_attention 的 allocation_base=mu，验证两条直接上限依赖；received 只在固定接收和评分时移除基权重中的增益通路。pooled_attention 在 $M<1$ 有总量导数，$M>1$ 无该项，$M=1$ 声明边界约定。

完整链路检查 query、key、评分头、增益头、记忆描述及写入。全零基权重处一般没有通常 Jacobian，遮罩自动微分与方向导数分别记录。跳过零 Full 和求内容后乘零的边界反向分别说明。

### 3.6 区域 Attention 的记忆 key

按[区域分配 §3.6](../local-semantics/weighted-message/region-allocation-learning-note.md#36-区域-attention-评分)核对两种 key 及其区域匹配：region_key=content_stats／content 均返回原描述字段中的 $d_{\mathrm{sel}}$ 维 key。

| 核对项 | 覆盖情形 |
|---|---|
| 参数与前向 | content_stats 恢复原拼接投影；content 只用两个记忆向量和独立的 $E_v^{\mathrm{key,mem}}$，中间宽度 $d_r$、输出宽度 $d_{\mathrm{sel}}$；ind 不使用 region_key |
| 直接统计依赖 | 固定两个 Mem 向量、query 与参数，只改变显式写入统计：content 的 key 不变；alpha_loc=0 时最终评分不变，非零 alpha_loc 时保留局部评分的统计路径 |
| 完整依赖 | 上一项不能替代完整求值检查；Mem、增益相关 query 权重、节点上限与区域头仍可依赖统计。KV qry 与循环 state 须保留当前内容和 Read 快照 |
| 范数与边界 | content 满足 $\|K_v^{\mathrm{sel}}\|\le\sqrt{d_{\mathrm{sel}}}$ 及教材 §3.2 的匹配界；覆盖零记忆和非零偏置，不得强制空记忆的 key 为零 |
| 独立与共享 | 固定输入与 Mem 时，独立 key 参数只改变对应匹配路径；与评分或证据显式共享编码时，反向汇总全部使用者的贡献 |
| 梯度与弱接收 | 对 query、记忆向量及编码参数作方向差分，覆盖经评分到正温度分配的非饱和分支；核对零接收候选删除及弱接收极限，沿用所选发送函数的适用条件 |

内容 key 与局部评分的组合在两份实例 §4.5 给出。改变 key 后重新求相应运行的评分间隔，不能把旧配置的硬化温度界直接作为新配置的保证。

### 4.2 原模型的对应范围

[Gated DeltaNet 附录 S](../local-semantics/weighted-message/recurrent-memory/gated-delta-learning-note.md#附录-s配置原模型对应与工作量)与 [SSD 附录 S](../local-semantics/weighted-message/recurrent-memory/ssd-learning-note.md#附录-s配置原模型对应与工作量)固定参考实现及开关。以相同归一化输入、单位接收、零矩阵与空缓存、零矩阵被动衰减进行对照，接收时间满足 $\theta_i=\theta_0+i\delta_{\mathrm{conv}}$。逐步比较投影、卷积、门、矩阵、读取、输出门与 Mix；先恢复普通序列混合器，再核对 Tide 的描述和外部内容函数。

GDN 核对 $\epsilon$ 所在位置、query 的 $d_k^{-1/2}$、每头 RMS 与门的顺序、矩阵采用 value-first 的轴排列。原实现对应还要求 RMS 缩放跨头共享、beta 投影无偏置，卷积偏置匹配。beta 取 sigmoid 范围，不能默用允许负特征值的其他开关。SSD 核对组数整除头数、B/C 共享映射、写入系数为 $d_h$、直通参数的逐头广播、norm_before_gate=False。参考卷积权重若按从旧到新排列，与教材按滞后 $0,1,\ldots$ 的顺序互相反转。

记录源码提交、配置、精度与误差；不同融合核的近似、累加顺序和低精度状态各自核对。本仓库给出实数公式对应，未据此宣称完成 GPU 内核或下游符合性验证。

### 4.3 带权、时间与反向

覆盖不等间隔、长空档、conv_size=1、不同 conv_stride、快照延后读取，以及在原本空槽插入零或逐渐变弱的事件。conv_stride 按逻辑时间确定抽头间距，与框架输出采样 stride 分别对应；实例取 conv_stride=$D$ 后应逐输入位置读取历史。比较新增事件之后的多次有效缓存、矩阵和读出，不能只看插入当步。复现[短卷积教材 §3](../local-semantics/weighted-message/recurrent-memory/causal-convolution-learning-note.md#3-弱接收与固定时间)的按事件移位反例；切分继续同时保留卷积与矩阵状态。

GDN 与 SSD 的正接收全候选都执行 Upd。测试本次未激活、下次激活且读取既有记忆的轨迹；本次发送控制不得改变本次缓存写入。给定完整驱动后，核对短卷积的预计算、仿射复合和逐步递归的所有中间结果，SSD 另与其历史展开式比较。缺失位置不能通过压紧序列后调用普通短卷积而隐式改变距离。

反向验证覆盖输入投影、历史卷积、保留与写入门、状态查询、输出门、归一化及区域描述。光滑点使用方向差分或独立自动微分核对，$w$ 截断处声明边界反向；区分记忆中性极限与当前内容方向的变化。门参数、归一化常数、低精度累加和状态反向截断均在验证报告中注明。有限时间连续性与固定输入转移范数界不替代训练梯度测量。

## 5. 数值性质、图与继续

数值比较按共同架构 §6 的固定图、参数、原始时间槽和有限切面进行，状态模块分别核对该节的局部假设。精确零消息增删与弱输入极限分别依照[性质对照](../local-semantics/weighted-message/region-allocation-learning-note.md#81-零接收与正温度连续性)选择函数范围，覆盖弱消息、弱候选、全零接收、空档和正时延反馈。

复现区域分配 §8.1 的固定总强度 Attention 算例，分别检查 mu 与 uniform 的零候选行为。混合组合使用全候选参考计算时，保留消息存在掩码；只有满足零消息删除条件时，才以显式零消息替代缺席并比较相同数值。

指定总量按区域分配 §7.2 比较 regional_total 与 regional_total_zero。用独立线性规划核对按评分填满的解，覆盖小数 $B$、非单位上限、唯一解、平票多解和全上限单点。唯一解条件下检查控制、有效状态与读出的收敛；平票排序不作为正则极限的默认保证。该零温函数保留总量头和区域大小容量。

复现区域分配 §7.3.2 的第二名间隔条件与四候选算例，核对有限正温度的精确分配。按该文 §7.4 比较 regional_threshold 与 regional_threshold_hard，按 §7.5 比较 constrained 与 hard_selection；两组均使用单位输入和各自硬运行的评分条件，区域阈值保留同一 Describe 与阈值头。另复现 §7.6 的平票、阈值临界及固定 $0<\mu_v<1$ 上限反例。

对满足相应条件的全区域 quad／固定 $\alpha>1$ 的 ent，逐事件取得正温度界，再按共同架构附录 A.4 取有限最小值，比较完整记录与切面。指定总量使用区域教材附录 A.4 的顶点间隔证明。其他情形的数值收敛按自己的支持性质判断；pooled_attention 的固定正温度连续性不直接给出整网硬化保证。

[全连接拓扑](../topologies/fully-connected-layered.md)与 [HB-Lattice 拓扑](../topologies/hb-lattice.md)分别核对节点、区域、边、端口和时间对齐；图规模按固定结构计数。[全连接实例](../instances/fully-connected-layered-weighted-message.md)核对单位接收、配置等值及 KV 写入时间；[HB 实例](../instances/hb-lattice-weighted-message.md)核对区域到达、候选并集及广播计数。两类实例均检查各记忆模块的完整绑定和实际工作量。复现 direct_attention 的三层总量 $1,1/4,1/8$ 与固定总强度 Attention（unit_attention）的 $1,1,1$；不同评分的响应另按函数核对。

整段、不同长度分段、逐位置和位置内部切面均比较完整记录与边界。左状态须含原始时钟、区域历史和在途消息；给定完整驱动窗口后再核对各模块的联合契约。变更参数、位置或记忆类型后的继续，使用另外声明的转换或重算规则。

自回归任务按[分块教材 §8.3](../timed-dag-chunk-prefill-learning-note.md#83-自回归输出的结构检查)声明输出坐标与各端口允许前缀。固定前缀、改变其余输入，比较输出值及输出是否存在；来源检查覆盖候选、激活与消息缺席的控制依赖。有限输入比较用于检验实现，一般前缀不变性由保守依赖集合及其包含关系证明。

报告明确通过范围、误差、未覆盖组合与复现入口。性能测量与训练质量独立报告，不从局部数学性质推出加速或效果。
