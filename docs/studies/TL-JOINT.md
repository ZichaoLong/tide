# TL-JOINT：联合证据的范围与下一步选项

问题：同一checkpoint上的语言质量和实际稀疏是否同时成立，是否已经推进到规模/局部结构？

审阅结论：A sparse相对dense的ΔNLL+0.023268、Full减49.73%；B sparse相对dense +0.002789、Full减49.03%，同时优于冻结原模型。各自文档bootstrap单侧95%上界低于原0.05容差。**小曝光、单seed、FC4下的质量/Full活动折衷已观察到；完整的语言能力、规模化、跨区域局部性联合目标尚未完成。**

反证：A小Transformer弱于unigram，无法作为充分训练的可靠语言参照；B参数接近的简单MLP和原模块继续训练均优于TIDE。FC8未训练，FC4没有内部消息，candidate/Upd/Read仍全执行。硬件速度没有同比例提高只列为工程事实，不用它否定当前实际Full稀疏。

不确定性：16测试文档、一个训练seed、短上下文和很少曝光；bootstrap未覆盖训练随机性和广泛语料。严格数值的有限超差及未知原因独立保留。分支贡献、架构独特性、泛化能力和实现等价不是同一结论。

有条件迁移：可保留KV/qry、全位置读出、冻结前缀cache及影子→CE日程作为下批起点，但更长上下文、多区域、不同局部模块或精度需要相关检查与独立质量评价。B保持不能证明A从零成功；A短上下文学习不能认证B整体局部化。此次不增加无条件科学支持边。
