# TL-A-TOPO：HB16分支汇合

问题：在近同参数下，入口→双分支→汇合能否形成有效的多区域语言计算和稀疏工作？HB16为4区域、3依赖层级、16节点/32边，669236可训练参数；B8/L32/128更新/seed11/512步LR前缀。quad在独立CPU1作业从零训练，不从Shannon切换。

结果：sparse完成128更新，验证NLL8.339376→6.748857；同v5确认集test **6.927488**。64步为7.146884，继续训练下降0.219397；但FC4 sparse同128步为**6.838241**，HB16差+0.089246，文档95%区间[0.066182,0.113455]。context-reset增加0.057520，表明在该干预下历史有有限贡献，不能由此证明中间分支独特价值。

实际工作：57264个candidate中32800个Full，比例**57.28%**，65610条内部消息。训练和小型终点检查各区域有活动及参数梯度；局部度数仍≤4。没有完整HB16 dense128终点，不能把42.72%的candidate未执行Full称为相对实测dense终点的工作减少，也不能用FC16 dense的不同边数作稀疏控制。

原dense成功86更新，第87次forward正支持下溢，重放已定位，失败保留。sparse终点小型core31个元素有限超差，原阈值不变；离散/因果/分块和三步精确恢复通过各自检查，长期恢复未查。HB40前提没有因sparse单边完成而自动补齐。

建议：先验收上游修复并补dense配对，再判断优化/曝光。128仍在学习，当前证据不支持加深收益，也不足以否定拓扑潜力。迁移需匹配分配、曝光、参数来源、局部依赖与新锁；不能推广到递归嵌套、长上下文或更大规模。
