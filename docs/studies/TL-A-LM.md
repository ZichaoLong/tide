# TL-A-LM：从零完整TIDE的语言与稀疏先导

问题：同token/更新预算、参数接近时，FC4语言模型能否学习，并用较少Full执行保留同架构稠密质量？

候选与对照：dense/sparse TIDE各268,581可训练参数（总参数268,589，含8个固定参数）；小Transformer257,344参数（少4.18%），train-only unigram辅助控制。固定KV/qry、width32、k2、温度0.25、B8/L32、128更新、seed11，各32,677有效训练目标；只比较同一A词表。

结果：test NLL dense **6.779286**，sparse **6.802554**，Transformer **7.022139**，unigram **6.946099**。稀疏减稠密为+0.023268，配对文档单侧95%上界0.037871，低于原0.05容差；Full从16,384减到8,236，减少49.73%。candidate/Upd/Read均16,384，没有对应减少。

机制与反证：两TIDE验证NLL由约8.322降至6.716/6.734。重置早期上下文分别增加test NLL 0.038864/0.046996；zero-core增加1.481691/1.460189。这支持该模型在L32内利用部分上下文、且核心输出有贡献，不证明TIDE独特性。Transformer尚弱于unigram，其上下文重置效应仅0.000165；因此当前对照明显欠训练，TIDE较好不能升级为普遍架构优势或实用语言质量。

边界：单seed、16测试文档/4,096目标、约3.3万训练目标、FP32有限探索。bootstrap只含该文档集的重采样不确定性，没有训练种子或广泛语料保证。FC4只有一个区域、零内部边，不能称跨区域局部通信或规模趋势。Full减少不等于总FLOPs/吞吐减半，A采样步时反而约13.51→14.07秒。

结论：**当前小曝光配置下，语言学习与约一半Full执行的质量折衷成立；一般语言可用性和规模化尚未验证。** 后续优先加强普通LM对照与训练曝光，再用独立seed/未观察确认文档核验；FC8作为有预算的第二实际容量点。固定来源、检查及原失败见[总报告](language-v3-results.md)，不追加当前任务。
