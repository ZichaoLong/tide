# TL-ACTIVITY-v9：约3%活动可继续学习，质量代价仍显著

问题：区域变宽、实际Full降低时，语言质量和增加依赖深度的收益是否保留？
20条主轨迹和6条R64延伸完成，全部物理稠密Full加遮罩。
原入口，节点宽64、FFN256；R32/h2为10区×32=320节点、约25.36M参数，
R64/h2为10区×64=640节点、约50.32M；R32/h3为22区×32=704节点、约55.47M。
这些不是规模组width128的HB88；不能把两种模型的质量与低活动拼接。

以下两seed均值，NLL越低越好；活动统计含padding位置，训练有效目标另计。

quad64M的接收/全主体**16.61%**、Full/候选**20.80%**；两seed的Full为3.456%/3.452%，
仍在原2.5–4%带。候选会更新记忆，Full活动比例不等于全部工作比例。
相比pooled差+0.3904 NLL（PPL约高47.8%），相比Bern差+0.3846；每seed配对文档区间均高于零。
本轮更长曝光略缩小与pooled的差，但没有消除，不能承诺继续训练必将追平。

深度反证也已收齐：R32/h2→h3，稠密Bern **4.3900→4.3354**，
quad **4.6423→4.7773**，两个seed均恶化；Full则由12.32%降至9.96%，接收34.12%降至23.02%。
深度、容量和实际活动一起变化，不能单归因于深度；应优先定位低活动下的覆盖/状态/有效容量，而非继续直接加深。

R32原入口未获延伸：原门槛用最后训练更新，两个seed14.21%/11.73%，未同时落8–12%带。
最终validation均值12.32%另列，不能事后换门槛。R64通过原门槛才成组六条延伸，未扩候选。

结论限于当前直接函数、语料、配方和所测活动带；独立确认集未测，全部Full仍实际计算，
没有宣称节省96.5%算力或达到相应加速。建议保留quad3与同形状两种稠密控制，
将节点宽度/区域布局与活动日程分开比较；与较强浅宽质量模型结合比继续复制窄节点更有依据。
