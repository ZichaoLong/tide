# v8 局部广覆盖：首轮结论

问题：在共同语言 next-token 口径下，哪些局部选择可学习、值得保留，哪些仍被执行问题遮蔽？
91 个具名配方分别由 FC/HB 承载，共182项；独立直接数学实现，主规格 FC16/HB40、d128、L128、B32、seed11。
每项最多1,048,576有效训练目标，同一32,768目标validation；mixed FC单独使用32节点/8层。
原始配置、参数、运行、Lens、失败及计算量见[逐项审阅](../evidence/direct-v8-results.json)，[研究表](direct-coverage-v8.md)保持原范围。

失败集中在递推记忆与quad分配相交的配置。连同一次seed22失败，共26次原失败：gated-delta 12、SSD 11、delta 1、mixed组合2。
均触发分配可行性残差>2e-5，范围约2.04e-5至0.652；6次在第一个optimizer更新前失败。
其他20次在不同训练阶段失败。小型公式/因果/恢复检查通过不认证完整长度下的所有执行；
不能把0.652统一当作轻微浮点误差，也不能据这些中断判断HB、SSD或gated-delta学习上限。

唯一具名修正`fc-mem-gated_delta-state-s11-r2`使用cd85637的quad相对坐标求根，
保持原阈值及同seed/data/曝光，从头完成1M，NLL=5.3088，原失败仍保留。
这支持该路径存在可修复的数值因素；没有保存原坏行，其他25个未完成运行身份的根因和修复覆盖仍未证明。
没有自动重新运行它们，也没有改变活动源码。

所有结果属于固定静态函数、精度、配方及短曝光。Full物理计算仍稠密，逻辑零发送不等于实际少算。
部分FC Attention/basis候选的最终NLL在显示精度内重合，不能把它们当作多个独立架构发现；
逐块记录并不全部逐位相同，也没有认证任意输入下等价。其他局部语义、共享、长状态及公共continuation迁移仍需桥接。
本轮没有打开test；validation参与筛选，种子复核仍使用相同validation。推荐保留已复核质量候选与quad温度1候选，
让失败路径的数值补齐只阻塞相应候选，不阻塞其余候选的后继真实稀疏/规模设计。
