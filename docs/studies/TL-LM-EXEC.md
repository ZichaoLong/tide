# TL-LM-EXEC：执行、数值、离散与恢复分开

问题：公共core-5接入全位置语言loss后，能否在本机开展可信、可恢复、有界的学习研究？

对照：固定数学0770593、foundation85d161d；v2的小型独立CPU/NPU机制及新进程恢复，与v3训练后的小型推理检查。新配方只改变探索曝光准入和编排，23个执行/依赖文件保持一致。

结果：v3七候选全部128步，29个阶段完成。A两个训练后TIDE的core离散/数值、分块与streaming小检查通过。B原冻结、原模块继续训练、MLP、TIDE dense/sparse五个模型的full/cache严格比较均有限失败，argmax一致；最大绝对差约8.68e-5–1.48e-4，原atol1e-5/rtol1e-4不改。B dense core的一个共享梯度元素超出原阈值（1.3933e-6 > 1.0186e-6）；其他已记录离散/因果/未来VJP机制通过，原因未知。执行退出0不覆盖这些严格失败。

恢复：七候选复用B2/L3三步、完整model/optimizer/RNG/游标的新进程精确比较。本次逐一CPU解码7个128步终点checkpoint，核对hash、身份、有限张量和完整应用键通过。没有实际中断续训，也没有128步不中断参考；不能扩大精确恢复范围。

成本：B8/L32完整组的预测可负担；B32虽有更高token吞吐，固定更新数下超出训练分项，因此复用B8。v1/v2校准时限、编排错误和65,536目标准入失败保留，不因v3完成改写。A/B服务分别约72.5/68.1分钟，全部后代已终止。

建议：允许已授权的有限数值探索继续评价学习，但严格等价保持失败。若后续改执行路径、局部模块或恢复条件，重新检查受影响部分；不以消除所有浮点差异为学习前提。来源与逐项数值见[终态JSON](../evidence/language-v3-terminal.json)和[checkpoint检查](../evidence/language-v3-checkpoint-inspection.json)。
