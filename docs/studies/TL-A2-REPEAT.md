# TL-A2-REPEAT — 三seed学会检索，稀疏有质量代价和局部时间收益

2026-11-08主代理审阅；范围为CPU FP32、16节点/4区域HB、width16、KV/qry、regional_total/k2、temp.25、B32、AdamW、固定400步。seed11复用第二批，22/33为本批四个新训练。同seed参数初值相同，Shannon/quad初始函数不同。[原始证据与逐例记录](../evidence/third-batch-progress-review.json)、[预先固定的研究表](third-batch.md)。

新集为2,048个唯一test映射，排除了旧test256的所有映射，标签/split/唯一性/排除规则复核通过。三个seed使用同一批映射，不算6,144个独立映射。三seed平均准确率dense99.805%、quad99.040%（相差−0.765个百分点）；准确率跨seed样本标准差0.258/1.127个百分点，仅作描述，不宣称总体非劣。quad三个seed的CE都略高，差0.00598/0.00975/0.01548；逐例配对dense独有正确44/3/10，quad独有正确8/0/2。不能称质量无损。

四个新训练全部达到原validation50%门槛，400步validation均100%；原test256为100/100/100/99.609%。去掉关联历史后val8.594%–12.5%，支持依赖历史检索。三个seed首次观测到50%的步数dense120/80/120、quad120/120/120，实际跨越只被40步验证间隔限定；seed22中quad达到门槛更晚，因此推理较快不等于更快学会。

工作减少不均匀：新test上的candidate/Upd只减少4.65%/9.81%/11.19%，Full和消息约少45%。每个模型先warmup两轮，再对相同64例做7轮交替顺序推理；窗口含完整CPU前向和内部工作计数，排除加载、loss/argmax、JSONL和Lens。同模型重复输出相对自己的warmup逐位相同。三对的计时范围dense9.102–9.294、9.072–9.292、9.087–9.285秒，quad8.337–8.553、7.954–8.098、7.851–8.006秒。这支持此次本机、固定checkpoint/输入的重复耗时观察；主机非独占（load约37–40），模型路由不同，不是同模型实现等价或通用硬件加速声明。

执行、学习通过；held-out离散规则和既有小型机制检查适用范围保留。原quad严格数值失败及未知原因不变。六个checkpoint的step400、config/installation/hash均核对并解码成功；这不是新做400步精确恢复。训练工作总计覆盖全部400步，81个详细观测点之外不声称已逐节点排除饥饿。

建议：接受“该小HB实现下三seed检索学习成立，稀疏以一定质量代价换取工作和局部耗时减少”。后续如需主张架构价值，先增加合法固定稀疏对照或明确质量容差下的比较；不能迁移为NPU速度、更大图、长空档或预训练旁路成功。固定稀疏的合法公共绑定须先确认，不复制执行核心。
