# TL-B-LM：利用预训练语言能力做完整单MLP承接

问题：在不以学新能力为必要条件的情况下，TIDE能否承接Qwen最后一个MLP，保留语言质量并减少部分实际工作？

设置：固定Qwen2.5-0.5B-Instruct revision `7ae557604adf67be50417f59c2c2f167def9a775`，其余骨干/head冻结，B8/L32、128更新、seed11，各32,503目标。替换候选前13步教师MSE、后115步CE，按原日程升到alpha=1；原MLP对照128步均CE。冻结前缀cache节省训练重复开销，其成本和预训练背景另列。

对照与结果：test NLL冻结原模型 **4.361484**，原MLP继续训练 **3.684206**，简单MLP **4.147179**，TIDE dense **4.234056**，TIDE sparse **4.236845**。TIDE可训练190,757参数，简单MLP189,952；原MLP13,074,432，参数量和CE暴露并不相同。cache尾部驻留参数量不是完整Qwen总参数。

稀疏减稠密NLL为+0.002789，单侧95%文档bootstrap上界0.011343；Full从16,384降到8,351，减少49.03%。稀疏相对冻结基线ΔNLL=-0.124639，单侧95%上界-0.064509。最终alpha=1，小型完整模型推理确认包装器旧MLP调用为0；不是旧10%混合保留教师计算的结果。

反证：稀疏TIDE仍差于原MLP继续训练 **0.552639**、简单MLP **0.089665**，均超过原0.05容差；后者参数接近、使用同替换日程。当前证据不支持TIDE独特架构优势。32维投影瓶颈、优化/曝光不足和局部函数表达差异尚未区分，不能把失败归为hidden无必要信息。

检查边界：五模型full/cache在原严格阈值下均有限失败且argmax相同；B dense core另有一个共享梯度元素超差，未知原因保留。单seed、小文档集、B1/L16与8-token生成检查不代表广泛能力保持。只替换最后一个MLP，其余注意力、全局词表head与预训练背景仍在，不能称整个模型局部化。

结论：**本次局部完整承接在固定自然文本上保持了冻结基线质量，并实现约一半Full执行；相对简单替换和原模块继续训练的质量优势未成立。** 下一步可用一个同样32维入口瓶颈、参数接近的稠密对照区分压缩与core因素；不自动扩大多层替换。详见[总报告](language-v3-results.md)。
