# TL-LM0：共同语言任务与数据

问题：用固定自然文本和独立划分支撑A从零语言训练与B预训练局部承接，避免将单答案合成任务当成语言能力。

材料：WikiText-2-raw固定revision `b08601e04326c79dfdd32d625aee71d232d685c3`，A使用训练集拟合4096词表BPE，B使用固定Qwen tokenizer。来源锁、文档边界和传输内容身份见[数据准备证据](../evidence/language-data-ready.json)。实际数据锁为`runs/lm-data-v1/tokens/data-lock.json`，所有v3运行引用同一hash。

结果：A/B均已使用L32覆盖全部有效目标位置训练128步。A采样32,677、B32,503目标；各路线内部候选暴露及顺序一致。validation为8文档/2,048目标，独立test为16文档/4,096目标。末块mask、生效目标及每文档损失保留，最终checkpoint固定为第128步，不从test选取。

解释边界：A/B共享原始文档及split设计，但词表、预训练背景和训练token池不同（A 517,581目标、B 64,304目标），不能横比PPL或声称两路线曝光语义完全相同。已完成精确重复/来源审计不排除近重复及Qwen预训练污染；小文档子集不代表完整WikiText或通用语言。L128未获本次训练资格。

建议：下一批保持可复现划分；若因本次结果调配方，现有test已成为已观察集，应预先冻结新的确认文档，再讨论广泛质量。增加曝光不替代独立确认。当前组执行完成，不自动下载新数据。
