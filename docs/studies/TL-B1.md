# TL-B1 — 预训练生长：旁路接入成立，收益尚未证实

2026-11-07三候选先导均已完成，Lens读回verified，服务正常退出且NPU锁与后代已释放。本轮不启动B正式重复：预先配置的25%验证门槛未达到，直接关闭旁路未改变准确率。

问题：在同预算继续训练下，一个小TIDE残差旁路是否进入梯度、产生实际预测贡献并改善关联检索？固定Qwen2.5-0.5B-Instruct及tokenizer、全骨干训练、相同随机分类头和符号映射；候选为原模型、TIDE旁路、简单MLP旁路。共同任务8键/8值、4关联、2延迟，seed11、B32、40步/1280训练例，SGD lr0.01/无momentum、clip1，NPU FP32 eager。预训练/指令后训练背景和约4.94亿骨干参数不能与A的从零小模型混同。

机制检查成立：零输出投影初态的任务/LM logits逐值保持；首步投影梯度非零，第二步进入分支；更新后分支能改变logits；NPU缓存续接及完整应用新进程恢复通过。它们不是质量收益证据，CPU cache与基座/下游FP32独立根严格失败仍保留，见启动审计。

实际学习贡献尚未建立。TIDE比原模型多答对7/128例，但CE较差；关闭TIDE分支不改变准确率，CE差约1.97e-5。训练路径扰动、梯度裁剪归一化变化、额外参数和有限样本/seed波动尚未排除。所有候选仍处于很弱的任务表现；单seed、40步、仅validation、无正式test不支持架构价值判断。关闭分支仅检测此已训练模型的依赖，不能替代重新训练对照。

可迁移的有限事实是该固定模型/任务/精度/公共接口下的中性初始化、梯度接入与同栈恢复配方；不能推导完整TIDE从零训练、HB、稀疏节省或多层替换成功。未来若用户验收后继续，可先比较冻结骨干后的head-only/TIDE/参数更接近的MLP，以区分旁路学习与骨干吸收（建议单NPU≤60分钟，先短CPU检查）；或先做图路径profile（单NPU≤30分钟）。两项均为后续可选申请，本轮未启动。

终态复核补充：冻结训练循环实际每步记录梯度/活动，配置log_every不等于实际观测节奏；当前计时包含这些开销，见[测量说明](../measurement-notes.md)。这不增加旁路预测贡献的证据，也不解除原严格失败。
