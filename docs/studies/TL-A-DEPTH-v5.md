# TL-A-DEPTH：四区域串联

问题：A从零训练由FC4增至FC16，区域间串联是否改善语言质量？新模型width32、4区域/16节点/48边、669108可训练参数；B8/L32/128更新/seed11/512步LR前缀、CPU1。对照是旧FC4同128步前缀在同一v5新文档上的复评，不是旧512终点。

结果：dense验证NLL8.339180→6.675042，test **6.864746**；FC4 dense **6.842736**。FC16减FC4为+0.022010，文档95%区间[0.004640,0.040867]。学习成立，但这次增加容量和串联没有质量收益。test有62464个Full、187392条内部消息；训练后小型检查各区域都有参数梯度和消息传递。

执行边界：dense128训练、普通test与小型推理完成，随后context-reset评价发生正支持下溢，原链failed；sparse未进入正式训练。不能把普通test完成写成整链正确，也没有FC16稠密/稀疏质量比较。训练后core92个元素严格超差，支持/因果及分块检查分开通过；三步新进程恢复通过，长期独立恢复未查。

解释尚未区分：训练曝光不足、深层优化、读出/信息路径和结构本身。参数比FC4多，不是纯深度因果实验；与HB16 sparse还改变分配规则，不能据两个终点孤立解释拓扑收益。

建议：保留dense权重和失败，独立补原表中的quad候选；新基座验收后再重做失败干预/必要dense比较。迁移条件是同任务、词表、训练曝光与新依赖身份明确，原严格阈值保持。不可外推长上下文或规模优势。
