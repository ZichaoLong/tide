# TL-B4-SHADOW — 两种分支均学会局部近似，MLP拟合更好

2026-11-08主代理终态审阅，待用户验收。[研究表](fourth-batch.md)、[原始曲线、尝试与checkpoint证据](../evidence/fourth-batch-terminal.json)。问题是小TIDE能否学习教师已有局部函数，比较对象为参数量接近的MLP。

教师固定，训练仅使用缓存x/y与train-only标准化。输入896→16+tanh；TIDE为公共FC/KV稠密width16/depth2、两区域、每例一个位置并重置；MLP共享16维瓶颈，中间宽2048。输出16→896，零输出初态对应训练均值预测。seed11、22；B128、128更新、每候选逻辑16,384例抽样；AdamW lr.001/eps1e-6/decay.01、clip1。预训练教师参数来源与新增随机参数分列，预训练成本没有匹配。

四者都优于均值相对MSE1.0并达到原val≤0.8门槛；MLP在两个种子的局部拟合均更好。TIDE输入、内部和输出组梯度在训练中非零；外部解析MSE导数、零初始化后的梯度进入及唯一optimizer参数检查通过。两候选新进程3步/B2模型+AdamW+标准化+数据游标+CPU/NPU/Python RNG比较精确通过，指tensor/值，不指checkpoint序列化字节。

B128校准遗漏单次20min限制，两TIDE首次尝试均按原上限失败，全部保留；分别从完整第96步checkpoint续接到128，源/config/cache/物理NPU14不变。没有128步不中断参考作独立精确比较。日志前缀与续接覆盖逻辑128步；未发布步骤重算量未知，实际耗时全部计入。每TIDE逻辑Full/candidate/Upd/Read各131,072，消息262,144，source rows327,680；这些由已发布96步前缀和32步续接相加，不是未知重算后的精确物理总量。

结论限于单位置教师函数近似，不能解释为学会新语言能力、跨token记忆或完整TIDE从零训练成功。当前未证实TIDE优于简单MLP。迁移到多位置状态/其他任务需独立检查。建议先改善保持评价的区分度，并对当前单位置B128执行开销做有限观测；不因训练完成自动扩层或加步。
