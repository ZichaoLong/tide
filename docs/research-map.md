## 节点与状态

| 类型 | 含义 |
| --- | --- |
| 目标 | 最终诉求或子目标，不是完成状态 |
| 起点 | 固定模型、数学或静态规划，资格按scope解释 |
| 实验 | 有稳定study ID、问题、对照、指标及预算的研究组，可以关联多个run |
| 结果 | 审阅结论位置；awaiting没有结果，不能因exit0改为支持 |
| 已有证据 | 固定来源的外部/基座结果，含范围和失败 |

| 状态 | 含义 |
| --- | --- |
| planned / 计划 | 尚未提交；不能当排队 |
| queued / 排队 | 已核对队列接受，尚未取得设备或开始计算 |
| running / 运行 | 已观测启动，不表示检查或学习通过 |
| completed / 执行完成 | 执行到终态；数值、语义、恢复、学习、性能分别判定 |
| failed / 失败 | 执行或严格检查明确失败，详情限定范围 |
| unchecked / 未检查 | 缺证据，不是通过 |
| awaiting / 待填 | 没有经审阅结论，不计入已有研究结果 |
| scoped / 已审阅且限定 | 有固定来源、scope和解释边界，才可作为科学支持/反证来源 |

组内可同时有完成、失败和未检查的尝试。TL-A0原FP32严格失败保留，小型FP64/机制/恢复通过分别限定。
旧full/cache有限失败的原阈值和未知原因也保留；有限数值探索不等于严格通过，学习效果不由执行状态推出。
最新进程状态以项目记录与`scripts/job.py status`为准；读取研究图不重启计算。

## 关系与条件迁移

| 关系 | 含义 |
| --- | --- |
| 分解 | 目标如何落实或分解 |
| 前提 / 参考 | 数据、数学、接入和已有证据的作用，不代表新研究成功 |
| 改造 | 模型/参数来源关系，不是效果支持 |
| 产出 | 研究对应的结果位置，未运行保持虚线 |
| 比较 | 共同评价及控制条件，不必是权重继承 |
| 迁移待验 | 条件启示，需要桥接；不自动传递资格 |
| 检验目标 | 拟议研究或结果对应目标，不是科学支持 |
| 支持 / 反证 | 只从scoped且有来源/范围的结果或证据发出；只在明确审阅后建立，不由完成状态推断 |

权重/状态谱系、执行前提、科学支持是不同关系。跨路线共享原始文档不意味着词表、参数、预训练或计算相同；PPL只在同词表内比较。
迁移启示必须列支撑结果、反证、改变的条件、未知耦合和最便宜的桥接检查；A+B各自成立不推出组合成立。
