# 研究图的读法

本图采用“目标层级＋带类型的研究关系图”。目标可以分解成树；研究组可以有多个来源、
共同对照和结果复用，因此整体采用graph。首批范围和预算见[研究表](studies/first-batch.md)，
实际作业与最新查看方式见[STATUS](STATUS.md)。图是审阅后的知识与决策记录，不实时轮询作业或 Lens。

## 节点

| 类型 | 含义 |
| --- | --- |
| 目标 | 最终诉求或可检验的子目标；不是完成状态 |
| 起点 | 待选择/校准的可靠模型，或固定数学约束 |
| 实验 | 带稳定 study ID、有问题、对照、验收和预算的一组研究；可以关联多个配置和run |
| 结果 | 审阅观察与结论的位置；`awaiting` 仍待填，不能因为作业退出零就改为已支持 |
| 已有证据 | 有固定来源的外部/基座结果；显示适用范围和失败 |

研究组和单次运行分层。详情可查看配置、固定实现、run ID、种子及项目记录的相对路径。
权重继承、完整checkpoint续接、执行前提、对照与科学支持分别记录。

## 状态与证据

| 状态 | 含义 |
| --- | --- |
| planned / 计划 | 已列入设计，但尚未提交 |
| queued / 排队 | 已核对队列接受；尚未取得设备或开始计算 |
| running / 运行 | 已观测启动；不表示检查或学习通过 |
| completed / 执行完成 | 执行到达终态；正确性、恢复和效果仍须各自判定 |
| failed / 失败 | 包含明确执行或严格检查失败；详情说明范围，不能概括所有客户端 |
| unchecked / 未检查 | 所需证据尚未获得，不能当作通过 |
| awaiting / 结论待填 | 结果位置还没有经审阅的结论 |
| scoped / 已审阅且限定 | 已给固定来源、适用域及结论边界；它才有资格作为支持或反证的来源 |

组内可以同时存在已完成、失败和未检查的项。TL-A0 的整体失败标记保留当前未解除的
FP32 稠密严格失败；CPU FP64 微型检查、完整恢复和 Lens 准入已有的有限通过分别说明。
它们都不是模型学习效果。原基座综合根的三项严格失败继续保留。
状态是最后审阅时的记录；最新进程状态以项目作业记录与 `scripts/job.py status` 为准。

## 连线

| 关系 | 含义 |
| --- | --- |
| 分解 | 最终目标与子目标 |
| 前提 / 参考 | 数学、接入与已有证据的作用，不代表实验已成功 |
| 改造 | 模型或参数来源关系，如从固定checkpoint新增残差旁路；不代表效果支持 |
| 产出 | 实验将产生哪些结果；结果未运行时仍为虚线 |
| 比较 | 共同任务/控制条件下需要进行的比较 |
| 迁移待验 | 条件相近的启示，需要桥接实验；不自动传递资格 |
| 检验目标 | 拟议实验与目标的关系，不是支持证据 |
| 支持 / 反证 | 仅允许从带固定来源与scope的scoped结果/证据发出；当前新研究尚无此类连线 |

鼠标点击或键盘Tab/Enter选节点，查看问题、条件、下一判断与资源；点击关系查看其含义。
“聚焦邻接”只强调直接关联，不计算迁移成功概率。筛选/搜索只改变可见性，不改证据。
“结果待填”节点会长期存在于设计图，但统计时不计为已录入研究结果。
所有拟议实验和迁移边使用虚线及文字标签；已有来源也显示范围限定，不能仅靠颜色判断。
路线和状态筛选只改变可见范围，不修改记录。完成运行的数量与已审阅结果的数量分别显示。

## 当前图的两条路线

**从零训练完整 TIDE**：TL-A0 可信接入 → TL-A1 小 FC/KV 延迟关联检索 → 条件满足后 TL-A2 小 HB 稠密/可学习稀疏比较。

**预训练模型生长**：固定 Qwen2.5-0.5B-Instruct → TL-B0 原模型校准 → TL-B1 原模型继续训练、TIDE旁路和简单MLP旁路对照。

TL-C 共用任务生成器、train/validation/test划分和质量指标，另外列预训练背景、参数与实际计算差异。
迁移启示必须给出成立条件；不从旁路收益推导完整 TIDE 从零训练成功。局部替换保留为后批候选，
首批终态由用户验收后再决定，不自动增加层数或研究规模。

Lens 使用项目名 `tide-learning-lab` 和同一study/run ID 查看指标。项目记录是权威，Lens是查看副本；
私有实例地址、数据目录和凭据不进入图数据。查看入口由本机交接提供，图页面不会向 Lens 发请求。

## 维护

编辑`research/map.json`的节点、关系、说明与布局，运行README中的生成/检查命令。
每条实际结果必须提供固定来源、比较口径、反证或未成功尝试、尚未区分的解释、迁移条件；
没有反证时也应明确写“尚未检查”，不能用空白代替。原失败和未测项保留，不从运行退出码自动生成支持关系。
HTML是确定生成的自包含产物，发布时可单独复制；Python不导入Torch。
仓库相对链接需要保留相邻文件才能离线打开；固定HTTPS来源只在用户点击时访问，没有外部脚本或隐式网络请求。

```sh
python scripts/render_map.py
python scripts/render_map.py --check
python -m unittest discover -s tests -p test_research_map.py -v
```

当前两份经主代理审阅、待用户验收的先导结果已填入图中：RA1为FC历史利用信号，R1为旁路接入成立但预测收益未证实。R2的HB结果仍待填；没有因这些结果自动增加广泛支持关系。来源链接固定到产生一页结论与原始记录的提交。
