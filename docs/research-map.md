# 研究图的读法

本图采用“目标层级＋带类型的研究关系图”。目标可以分解成树；实验可以有多个来源、
共同对照和结果复用，因此整体采用graph。它与排期甘特图互补：当前先表达研究理由与证据，
实际作业和预算确定后才添加日程。尚未实现自动排队、项目管理后台或模型结果自动导入。

## 节点

| 类型 | 含义 |
| --- | --- |
| 目标 | 最终诉求或可检验的子目标；不是完成状态 |
| 起点 | 待选择/校准的可靠模型，或固定数学约束 |
| 实验 | 有问题、改动、对照、验收和资源需求的一组研究；不是一次run |
| 结果 | 观察和结论的记录位置；当前灰色节点均待填，没有实验数值 |
| 已有证据 | 有固定来源的外部/基座结果；显示适用范围和失败 |

研究实验与单次运行分层：以后一个实验可关联多个配置、种子和运行。
权重继承、完整checkpoint续接、对照与科学支持也分别记录。

## 连线

| 关系 | 含义 |
| --- | --- |
| 分解 | 最终目标与子目标 |
| 前提 / 参考 | 数学、接入与已有证据的作用，不代表实验已成功 |
| 改造 | 从基线到旁路、替换或新的局部组合；当前全为拟议 |
| 产出 | 实验将产生哪些结果；结果未运行时仍为虚线 |
| 比较 | 共同任务/控制条件下需要进行的比较 |
| 迁移待验 | 条件相近的启示，需要桥接实验；不自动传递资格 |
| 检验目标 | 拟议实验与目标的关系，不是支持证据 |
| 支持 / 反证 | 只有带实际来源的结果才能添加；当前新研究尚无此类连线 |

鼠标点击或键盘Tab/Enter选节点，查看问题、条件、下一判断与资源；点击关系查看其含义。
“聚焦邻接”只强调直接关联，不计算迁移成功概率。筛选/搜索只改变可见性，不改证据。
“结果待填”节点会长期存在于设计图，但统计时不计为已完成实验。
所有拟议实验和迁移边使用虚线及文字标签；已有来源也显示范围限定，不能仅靠颜色判断。

## 当前图的两条路线

可靠模型→校准及原模型继续训练对照→Tide旁路→局部替换。
固定core-5→小型完整模型→HB稀疏多区域。
两线用共同任务和有界桥接比较连接，再判断局部化、稀疏及质量/成本目标。
这里不承诺一条路线总优于另一条，也不从旁路收益直接推导纯Tide可训练。

## 维护

编辑`research/map.json`的节点、关系、说明与布局，运行README中的生成/检查命令。
每条实际结果必须提供固定来源；原失败和未测项保留。新研究统一实施前不填造预算或实验结论。
HTML是确定生成的自包含产物，发布时可单独复制；Python不导入Torch。
正式数据schema、真实结果导入、目标折叠、跨实验筛选和资源视图根据后续对齐逐步补充。
