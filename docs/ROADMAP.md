# 后续可选工作

按具体需求选有限输入与停止条件；以下不是自动继续的本轮任务。

1. **数值剩余边界。** 对FP32整图更新超差、BF16上游评分/历史差异做窄见证；
   同输入求解器错误与真实评分跨界分开。新quad修复只解决已定位错误face，
   不假定现有fallback能覆盖所有近边界情形。继续保留原阈值和失败，不改训练epsilon来制造通过。
2. **分配与回退成本。** 新生产树需重新测量性能。可压紧真正请求fallback的行，或改进
   稳定face求解，保留精确零、正支持与声明VJP。旧请求324/执行49152行是定位证据，
   不能预先承诺相同比例整体加速。
3. **FFN与padding。** 直接有效行进入较少grouped contractions，复用静态owner顺序，
   减少多桶、排序、空bank跨度与反向组装。W/P/WP此前省显存而未赢同batch吞吐，
   并有数值资格缺口；先限定适用范围，再测完整训练/推理，不从少行数推断速度。
4. **私有KV与Attention。** 持续bank/窗口布局可减少拼接、摘要、整理和state join；
   保留原始int64、窗口淘汰、正写入、零接收导数和跨块梯度。带权Attention融合
   必须保留零权重导数，静态mask不自动等价。
5. **参数与数学实例选择。** 共享基座真正合成较大GEMM仍有执行机会，不能把重复展开
   当计算复用。若改变FFN共享、Full频率或通信规则，应声明新实例与模块配比，并由下游验证效果。
6. **覆盖与存储。** 9B训练、FFN补参候选训练恢复、新Timed/多NPU/CUDA组合按需求单独资格。
   CPU NUMA计时差异仍未解释。旧完整载荷已明确退役；若需要更深数值定位，从Git审阅记录与源码确定
   新的有限重捕获输入与预算；旧局部见证也已退役，不将原路径当可用性保证。
