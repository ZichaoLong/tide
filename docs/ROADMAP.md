# Current delivery

1. New fixed-source package, minimal rules and execution entry.
2. Batched FC K, encoded regional attention, quad/pool, gradients and continuation.
3. All main local choices: S/X, four reception profiles, three allocations,
   independent/region_shared/layer_shared parameters.
4. HB-Lattice, Exchange, Multiscale Settle/Timed and legal declared options.
5. CPU/NPU implementation choices; native kernels/node parallelism where useful.
6. Finite inference/grad-forward/training comparisons against matched optimized
   Transformer/SSD models and same-function direct formulas where useful.

Every main choice is a delivery item, not an unsupported flag. Combinations are
configurable where the fixed binding permits them; tests need not enumerate all.
Old teaching bindings, LH-DAG/PDG, arbitrary graph executors, old client matrices,
full action records and general state decoders are excluded from this delivery.

Performance uses actual work, memory and full timing. No prescribed speedup;
large gaps require an explanation or an explicit next implementation decision.
