# 从新线程接续

默认只读 `AGENTS.md`、[研究章程](RESEARCH_CHARTER.md) 和 [当前状态](STATUS.md)。
旧倾向、记录、代码和结论不进入上下文；只有用户明确提醒回顾时按范围查找。

## 新线程提供什么

- 新语义的文件路径、仓库或修订；若尚在修改，说明本轮关注的定义范围。
- 新基座的目录、分支或实现入口，以及本轮已可用的能力。进行中的版本可以先只读对齐，执行前再固定身份。
- 当前最希望回答的问题；也可要求代理根据新材料提出少量可区分的方案。
- 本线程的授权范围与可接受的墙钟、模型/数据规模、设备和磁盘约束。未确定部分明确列为待定，不能套用旧批次上限。

## 第一份交付

一页研究约定：问题、当前语义/实现、候选与合理校准的对照、共同数据与评价、
改变量、指标、有限预算、停止条件和保存范围。可使用 [研究表模板](research-design.md)。
不要先恢复旧流水线；先核对当前问题所需的最小训练/推理契约和实际成本。

如果上游部分能力仍在实现，只阻塞依赖该能力的工作；可先完成契约对齐、
评价定义和其他已具备前提且获授权的工作。无需等待一套覆盖所有问题的基座。
执行授权具备后，可连续完成有依赖的检查与训练阶段，独立工作按资源实测并行。

```text
不要主动回顾历史倾向、结果、旧实现、依赖锁或过去会话；需要回顾时我会明确提出。

长期目标是同一模型的自然语言 next-token 质量，同时推进规模化、低活动和局部化。
语义与基座以中短期研究问题为单位迭代，不预设统一架构或统一基座。

本轮新语义来源：<路径 / 修订及范围>
本轮基座来源：<目录 / 分支 / 实现入口及可用能力>

```

无需把旧会话全文或旧 AGENTS 快照粘贴到新线程；使用仓库当前入口即可。
