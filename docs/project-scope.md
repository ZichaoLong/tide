# 产品路线与当前语义周期

本页记录用户已经确认的持续约定；当前进度在 [STATUS](STATUS.md)，本周期待办在
[ROADMAP](ROADMAP.md)。具体实现策略可依据证据调整，产品范围变更由用户确定。

## 两条路线

| 路线 | 产品与边界 | 启动依据 |
|---|---|---|
| 实例实现，当前常态 | 固定上游选定实例的正确、可训练、高效实现，按下游需求扩展 | 采用的数学版本、实例绑定和实际需求 |
| 通用基座，长期方向 | 更一般的图语义、局部组合与执行能力 | 将来单独明确启动 |

实例路线可以长期持续，不因某次交付结束就自动进入通用基座路线。
长期方向不向当前实例附加接口、兼容性、通用调度或全后端矩阵义务。
数据、任务头、任务 loss、训练配方与效果搜索由下游实验承担；本库验证训练机制。

## 当前周期

数学固定到 `4f5b9f20a4030d68ee66ae2d26e34659a5e37234`，身份与 108 个文件的
校验值在 [upstream.json](upstream.json)，快照是 `math/`。采用的绑定见
[semantics](semantics.md)。快照中还包含探索、历史和其他数学条目；它们不是当前功能清单。

当前产品是 FC、HB-Lattice、HB-Exchange、HB-Multiscale Settle/Timed；覆盖 K/S/X、
四种接收、quad/Shannon/pool、三档参数归属及主绑定的合法配置。
本线程显式加入[记忆绑定扩展](memory-candidates.md)：反向混合、共同窄Q/K/V内部通道、
分模块记忆区域共享与独立Full FFN尺寸；它们不改变固定快照，也不自动替换默认。
当前 `src/tide` 是活跃实现；上一轮交付不等于上一代实现。

实际训练及后续训练优化优先 FP32；BF16 保留为次优先级的可选精度，已有实现与证据继续保留。
两者的正确性、稳定性和性能仍属于范围，CPU FP64 用于有限精度诊断。
精度优先级不是数值通过声明；资格事实从 STATUS 和固定证据读取。
FP16、旧教学绑定、LH-DAG/PDG 和任意图引擎不属于这个周期。

## 实现与验证原则

- 语义正确第一，性能第二；接口服务于张量贯穿、清晰职责与可替换局部实现。
- B、L 和相容节点按数学依赖批量处理；需要时允许按实例、模块或后端分别实现。
- 现有 API、架构和放置分类可以重设计。兼容代价高时由消费者迁移，不保留昂贵包装。
- 验证直接覆盖值、作用支持、状态、梯度、优化器及必要恢复；完整行动日志、通用内部
  解码、任意中间梯度根不是当前产品要求。
- 基本模块与有价值的小范围组合分别检查；组合数量大时依赖明确接口、适用条件和经验，
  不以遍历组合为工作前提。
- 数值错误需要修复；有限舍入差异经过有界调查后记录。完整训练与含梯度前向分别计费。
- 性能比较遵守 [四类联合匹配](benchmark-contract.md)。不同数学函数是计算参考，
  不能认证语义等价或模型质量。

## 目标、选择与经验的区别

上面的范围和原则是已确认约定。ROADMAP 的阶段、代表测点和热点顺序是可调整工程计划；
例如查询分桶、LibTorch 或 resident 是需要证据决定的方案，不是永久任务。
[性能经验](performance-lessons.md)记录机制、适用条件与正负结果；经验不能扩展验收范围。
