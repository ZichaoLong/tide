# Explicit public FP32 norm Read — 2026-09-30

Clean `0e66d89` passes 8,901 complete CPU regression tests and eight CPU CTests,
18 Python/NPU and 18 native-adapter/NPU cases, plus the independent standalone
LibTorch/NPU precision gate. The [manifest](norm32-20260930.json) records exact
source and hashes of existing build, test, profile and raw trace records.

`norm-fp32-v1` converts the visible payload to FP32 before L2 reduction and returns
FP32. FP16/FP32/FP64 payloads use that explicit contract. Its ordinary conversion
and norm VJP preserve a connected zero at zero norm; unused linear Read parameters
remain disconnected. The old `norm-fp64-v1` is unchanged and still refused on NPU.
Changing the Read profile changes graph identity; route/tie differences caused by
precision are not interchangeable configurations.

The 18-case suites cover PDG, TimedDAG and SettleGraph, streaming/online greedy,
and content/old/proposal Read. They check independent CPU comparison, observables,
VJPs, three updates and continuation. Standalone LibTorch checks six schedule/Read
combinations and 18 updates, with FP16/FP32 analytic payload checks. CPU retains
FP64 payload/reference coverage. These are short infrastructure training tests;
no model convergence or full-size throughput conclusion is claimed.

A separate candidate-only native profile of `norm32-timed-dag-proposal-greedy`
contains 604 kernels: 500 AIVEC, 84 mixed AIV and 20 AI Core, including 12 Norm
kernels. There are 97 host scalar-read events and 72 async memcpy events; no
observed fallback event. This certifies the measured placement only. The public
candidate still uses host scheduling with NPU tensor computation, including
backward/update; it does not provide device-resident training.
