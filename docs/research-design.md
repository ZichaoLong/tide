# 新周期研究表模板

先围绕一个可区分的问题填表，不预设架构、路由、数据或旧配方。
当前尚无已填写并获执行授权的研究表。

| 内容 | 本批需明确 |
| --- | --- |
| 研究问题 | 与语言质量、规模、活动或局部性交叉的哪个判断有关 |
| 语义与实现身份 | 语义修订、基座/特例实现、实验源码及实际依赖 |
| 候选与对照 | 各改一个什么；对照如何进行有限而合理的配方校准 |
| 数据与评价 | 语料、tokenizer、划分、上下文、有效曝光与评价口径 |
| 参数与工作 | 总/可训练/活跃参数、深度、局部边界、逻辑活动、实际工作和吞吐 |
| 训练配方 | batch、序列长度、optimizer、学习率日程、loss 与种子 |
| 检查与验收 | 数值、离散机制、梯度、共享参数、optimizer、恢复、推理和学习分别判断 |
| 资源与时限 | 设备、并行度、实测单步/内存、墙钟截止、并发写入峰值与保留空间 |
| 停止与后继 | 什么情况下停止哪条路径；哪些后继阶段已授权，哪些需要后续决策 |
| 记录与保留 | 配置/run ID、关键指标、权重/optimizer 保留范围、日志与恢复方式 |

不同实现之间的数值一致性和不同模型之间的质量差异使用不同口径。
探索性结果、严格验收和未检查项独立记录，不通过改变问题或阈值追认成功。
检查规模以当前契约需要为准，随后推进能够回答研究问题的实际训练量。

尽量保持同一周期的数据和评价可比较。频繁查看的验证集属于开发证据；
关键结论使用预先约定的独立确认，不把反复查看的集合重新称为未见数据。

上游语义、基座实现和实验各自说明负责的对象；模型函数变更与执行优化分开。
缺口应附具体公式/接口、最小例子和受阻范围，无需扩大成通用平台建设。
