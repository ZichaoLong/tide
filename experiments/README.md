# TIDE 每日实验记录

本目录按自然日记录真正采用的实验设置、结果和结论。理论理由与长期政策仍由仓库 README 和 `docs/` 维护；这里回答“当天到底准备怎样跑、实际跑出了什么”。

## 记录规则

1. 每个日期使用一个 `YYYY-MM-DD.md` 文件；同一天有多次修改，就在同一文件中追加带时间的小节。
2. 每份记录先写相对上一份记录的变化，再给出当天完整有效设置。读者不必拼接多份文档才能复现实验。
3. 设置、结果和解释分开写。没有实际运行时明确写“未运行”，不把计划当作结果。
4. 已经运行过的旧设置不回写覆盖。发现事实错误时，在旧记录加勘误，并在新日期说明影响。
5. 稳定不变的内容继续用简短公式或伪代码复述；新记录重点解释发生变化的坐标和原因。
6. 每次真实运行另存机器可读 manifest，至少固定代码 commit、配置、checkpoint 和数据哈希、seed、设备、精度与输出目录。
