# TIDE Learning Lab

这是 `ZichaoLong/tide` 的独立实验分支，负责模型训练与推理研究、对照和评价。

**长期目标：在同一个模型上，让自然语言 next-token 质量接近合理调参的对照，同时推进数据、容量与依赖深度扩展、低活动和局部交互。**

语义和实现围绕中短期研究问题持续迭代。每批固定所用版本，无需先完成统一架构或通用基座。

从本线程的用户任务出发。查看进度可以在仓库根目录运行 `python scripts/status.py`，程序会同时显示采样时间和上次交接。需要机器可读记录时加 `--json`。同一批次沿冻结计划接续，新周期按用户这次选定的问题、来源和预算起步。旧倾向和历史仅按用户明确要求查找。

| 本次要做什么 | 入口 |
|---|---|
| 查当前阶段、作业或阻断 | [状态命令](scripts/status.py) · [当前交接](docs/STATUS.md) |
| 接续同一批 | [当前待办](docs/ROADMAP.md) · [本机与干净检出](docs/README.md#接续同一批) |
| 在本机、ModelArts 或两处执行冻结任务 | [生成计划、发现批次、跨作业恢复与项目复核](docs/portable-execution.md) |
| 定位失败、修改并验证 | [源码与测试](docs/README.md#定位和修改) · [r24 从故障到正式采用](docs/requests/pilot-r3-r24-quad.md) |
| 开一个新周期 | [新周期工作规则](AGENTS.md#新周期工作规则) |
